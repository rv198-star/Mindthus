## Release scope

`v1.12.0` is the 1.x Stable minor release for Explain human-facing delivery and TPlan
progress/remaining-work presentation. It includes:

- `Explain / 解释与表达` as Mindthus's default human-facing delivery Skill, with clarity,
  brief, ELI5, audience, and HTML modes while keeping upstream judgment authority;
- direct Explain integration from 3L5S, SELA, MPG, SRA, EDSP, WAE, TVG, TPlan and
  `using-mindthus`;
- optional TPlan `work_plan`, source-backed text/JSON/HTML progress views and workload
  shares without deriving false completion percentages;
- ChatGPT Visualizations / `app_block` as the verified interactive HTML adapter, plus
  self-contained HTML export when explicitly requested.

Current Stable policy no longer requires a synchronized ROI Beta. No `v1.12.0-roi-beta`
tag or asset was created. Existing historical Beta sources/assets remain unchanged.
TPlan runtime generation remains `1.5.4`.
