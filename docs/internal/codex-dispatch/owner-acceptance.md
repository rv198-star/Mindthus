## 实际发生了什么

用户要求开一个 Sol 6.2 分支实现。A 保持原会话（Astra 6.2 / max），从当前宿主的可用范围中选用指定的 Sol 6.2 和本机默认 xhigh，开一个带独立 Git 工作区的普通会话 B。首条消息带上设计哈希、写入权限和交付约定。创建先返回待建引用；A 在原宿主核实正式会话及首轮实际型号、档位和工作区。整批仅有一次创建，A 未再发派工或催办消息。B 自主处理读取协议差异，交付固定提交，由 A 查看其结果。
