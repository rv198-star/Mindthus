# Explain 默认人向交付：决议与开发期对照

## 决议与依据

用户批准：Mindthus 各方法形成判断；当前 Agent 默认使用正式 Explain Skill 完成人向
结果交付。默认 clarity，增强模式按需。此前 `4bcaf760` 的“共享基线默认生效、完整
Skill 按需触发”被本决议替代。这是后续接入策略变更，不把原 Design Spec §25 的
“全系统默认自动 Explain”非目标重新解释成早已批准。

## 实际接线

八个方法和 using-mindthus 直接链接 `skills/explain/SKILL.md`；AGENTS 与 README 同步。
缺少有效规则上下文时读取正式入口；已加载时复用，按需加载 HTML/TPlan/表达资源。
不是用户加 flag 才启用，也不是复制几条基础规则就算默认使用。加工强度由 Explain
内部决定，已经清楚的结果可保持原样。

机器/精确格式、必需产物链接、内部记录及各方法的证据要求不改；短确认与心跳不扩写。
不新增 Agent、模型调用、生成原答案后重写、调用回执、运行时状态机或新判断 owner。
TPlan 的已验收 Visualizations 和运行时实现未修改。

## 同源对照的证据范围

以下六例是当前 Agent 根据明确源材料构造并复核的开发期固定对照，不是生产数据。
“基线表达”也是构造样例，不是从历史模型调用提取的原答案；“Explain 表达”按本轮
正式规则生成。没有执行独立 baseline/candidate 模型采样，也没有第二模型盲评。
测试只能证明这些固定输出保留了指定限定、链接和精确字节，不能证明所有模型默认
执行一定提升理解，也不能证明模型时延或成本减少。

机读样例见 [六个固定用例](../../../tests/fixtures/explain-default-delivery.json)。

### short-clear

**源材料：** 补丁已应用。8项回归通过。尚未部署。

**基线表达：**

```text
补丁已应用。8项回归通过。尚未部署。
```

**本次 Explain 表达：**

```text
补丁已应用。8项回归通过。尚未部署。
```

**同源复核：** 原表达已充分；默认使用Explain允许不改写，不为显示加工而扩写。

### qualified-judgment

**源材料：** 测试仅包含1000个合成请求，不包含生产数据。方法owner建议只做10%流量灰度，不授权全量上线。若错误率超过2%，立即回滚；由值班负责人批准启动。证据见 evidence/canary-01.md。

**基线表达：**

```text
测试：1000个合成请求；无生产数据。建议：10%流量灰度，非全量上线授权。错误率超过2%回滚。值班负责人批准启动。依据：evidence/canary-01.md。
```

**本次 Explain 表达：**

```text
建议先做10%流量灰度，由值班负责人批准启动；这不是全量上线授权。

依据目前只有1000个合成请求，不包含生产数据。灰度期间若错误率超过2%，立即回滚。证据：evidence/canary-01.md。
```

**同源复核：** 先说明建议及授权边界，再说明证据限度和回滚条件；没有把测试通过升级为上线许可。

### tplan-progress

**源材料：** 共6个工作块，4个已验收，1个回归测试进行中，1个等待外部验收回执。剩余测试6点，交付验收4点，同单位完整估算合计10点。没有整体工作量进度百分比，没有并行资源声明。标准报告：[执行报告](reports/execution-cost-tree.md) 与 [执行图](reports/execution-cost-tree.svg)。

**基线表达：**

```text
工作块6，已验收4；测试进行中6点，验收等回执4点；剩余10点。整体百分比未提供，并行条件未提供。[执行报告](reports/execution-cost-tree.md) / [执行图](reports/execution-cost-tree.svg)。
```

**本次 Explain 表达：**

```text
6个工作块中4个已验收。剩下回归测试正在进行，交付验收等待外部验收回执。

已估剩余工作共10点：测试6点，占剩余工作量60%；交付验收4点，占40%。这些比例只表示剩余构成，不是整体完成率。当前没有并行资源声明，不能确认可并行。

[执行报告](reports/execution-cost-tree.md) · [执行图](reports/execution-cost-tree.svg)
```

**同源复核：** 任务计数与工作量分开；60%/40%仅为已给定剩余点数的透明算术；标准报告链接保留。

### exact-json

**源材料：** 用户要求只返回这个JSON，不加围栏或解释：
{"status":"blocked","count":0}


**基线表达：**

```text
{"status":"blocked","count":0}
```

**本次 Explain 表达：**

```text
{"status":"blocked","count":0}
```

**同源复核：** 纯机器交付保持UTF-8字节一致；不自动增加解释。

### exact-command

**源材料：** 用户要求原样返回命令，仅命令，不执行：python3 -m unittest tests.test_explain_contract -q

**基线表达：**

```text
python3 -m unittest tests.test_explain_contract -q
```

**本次 Explain 表达：**

```text
python3 -m unittest tests.test_explain_contract -q
```

**同源复核：** 精确命令原样保留，不执行，也不制造执行结果。

### short-ack

**源材料：** 用户只要求确认收到材料，不要求报告。

**基线表达：**

```text
已收到材料。
```

**本次 Explain 表达：**

```text
已收到材料。
```

**同源复核：** 简短确认直接保留，不把默认交付扩大为每句话都写报告。

## 成本记录

实测 UTF-8 文件大小（不是 token 数）：

| 项目 | 字节数 |
| --- | ---: |
| 旧 Explain 正式入口（4bcaf760） | 10126 |
| 本轮正式入口 | 10198 |
| 差值 | +72 |

旧策略在普通交付时可能只读取较短合同，因此“入口只增加少量字节”不等于默认使用
Skill 没有加载成本。首次读取、按需资源和最终输出均可能增加上下文或延迟；上下文
复用减少重复读取，但不能把收益量化为未经测量的 token/秒。

本轮未调用额外模型。质量与成本的独立模型 A/B 测量未执行；以上对照不是其替代品。
验证耗时仅作为工程测试耗时记录于 PR #224 / task，不当作模型交付时延。
