## 结论与限定 {#result span=2}
```callout info
6个工作块中4个已验收；剩余估计合计10点
本页为开发期假设／语义样例，不代表生产进度。回归测试进行中，交付验收等待外部回执。
测试与验收分别占剩余量的60%和40%，这些不是整体完成率。整体工作量百分比未知；没有并行资源声明，并行情况未知。
```

## 工作块与状态 {#status}
| 项目 | 已声明情况 |
| --- | --- |
| 工作块总数 | 6个 |
| 已验收工作块 | 4个 |
| 回归测试 | 进行中 |
| 交付验收 | 等待外部回执 |
| 并行情况 | 未知；没有并行资源声明 |

## 剩余量与构成 {#remaining}
```progress
剩余总量 | 10 | 点 | 已声明同单位剩余估计：测试6点＋验收4点
测试占剩余量 | 60 | % | 测试6点，占剩余10点的60%；不是整体完成率
验收占剩余量 | 40 | % | 验收4点，占剩余10点的40%；不是整体完成率
整体工作量进度 | ? | % | 没有整体工作量进度百分比，不生成总体完成率
```

## 读数说明 {#details collapsed}
“4个已验收／共6个”表示工作块计数；“10点”表示同单位剩余估计。两种口径不能直接换算为整体完成率。

60%和40%的分母都是剩余10点，表示剩余量构成，不表示测试或验收各自已完成的比例。
