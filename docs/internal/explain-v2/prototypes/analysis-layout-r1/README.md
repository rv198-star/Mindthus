## 本轮定位

Owner 认可功能，但不认可连续两轮的视觉方向。此前 compact-style-r1 主要改变字号、颜色与外框，未充分改变“章节顺序阅读”的组织方式。用户随后同意参考 Dashboard / Report 页面，先用既有材料做分析工作台式原型，再根据实际视觉反馈提炼通用布局。

本轮在 `feat/explain-html-v2`、固定基线 `ba40a9fd8494646be7b5aa24489adf9334b1aa4f` 上新增独立开发原型。**没有修改 `skills/`、TPlan、生产渲染入口、原有组件语法或原 18 次模型生成结果；没有合并、发布或新增模型调用。**

这是人工组织信息的开发样板，不是“任意稿件已经可以自动生成同样页面”的声明。`build.py` 中四个内容函数是显式样例，不进入运行时，也不包装成场景专用产品适配器。

## 四份可操作视图

| 样例 | 主要结构 | 既有信息与边界 |
| --- | --- | --- |
| 执行简报 | 低矮指标横带；工作明细为主区；侧边约束、下一步；下方证据与前置并排 | 原任务待验证；CSV 已覆盖、XLSX 未覆盖；已估 5–7 人时外仍有未估项 |
| 进度分析 | 状态计数、工作表、剩余量构成同屏 | 4/6 只作计数；6+4 点及 60/40% 只作剩余量构成；整体完成率与并行情况未知 |
| 方案比较 | 同维度矩阵与旁侧决策依据；时间条只比较原假设时间 | 建议 A 的依据为必需的离线条件；两次开发试验，没有生产验证；执行须批准 |
| 机制图解 | 两条独立分支时序并排；邻接阅读说明；原完整关系图保留 | 原稿 6 节点、8 关系保留；有效/无效指格式；不创造内容真实性或授权结论 |

共同元素是指标带、主要分析区、邻接信息区与来源下钻，而不是统一把每一节缩成卡片。没有欢迎插画、虚构趋势、装饰地图、空白统计项、假筛选项或业务执行按钮。

工作表筛选与搜索、深浅色、线性阅读、原材料展开与复制、图形原始尺寸切换都是真实的本地阅读操作。禁用 JavaScript 时完整正文和原材料可读，增强控件隐藏；窄屏表格局部横向滚动，避免把所有字段挤成极小字。

## 来源绑定与语义核对

- 执行简报依据：`docs/internal/explain-v1/samples/d-source.md` 原始演示材料。
- 其余视图依据：`docs/internal/explain-v2/evidence/d2/model-r1/runs/31B|21B|11B/generated.md`。
- `build.py` 每次核对上述内容与固定 baseline 完全相同，原文嵌入每份新页面，浏览器检查重新校验其 SHA-256。
- 上一版业务报告曾把 `权限确认 → 联调` 和 `联调 → 交付` 画入新时序，而原材料没有明确声明这两条依赖。本轮业务页仅保留 `格式兼容检查通过 → 联调` 与 `测试凭证发放 → 权限确认`。这是基于原材料的定点更正，不能称为与上一版 HTML 逐字相同。
- 机制页的两幅时序分别明确标记有效与无效分支，避免把互斥分支误读成一次请求中全部顺次发生。有效分支的结果返回压缩了结果节点，旁注明确说明，下方完整原图仍保留所有节点和关系。
- 本轮比较的是**同一材料的不同组织方式**，不使用“仅 CSS 不同”的上一轮验收口径。

## 真实检查与测量

最终浏览器矩阵：4 样例 × Node/Python × 1440/1280/390px × JavaScript 开关，共 **48/48** 通过。覆盖原文摘要、关键事实、整页溢出、图形边界、图关系数量、键盘来源展开、真实筛选/搜索、颜色/布局切换与图形尺寸操作；请求记录和脚本错误均为零。

另有 **2/2** 打印检查：在筛选后的状态进入打印时，仍输出完整工作行。离线对照查看器 **24/24** 通过（4 样例 × 新版/上一版/并排截图 × 桌面/手机），并在 sandbox 中验证复制权限不足时的原文选中回退。

业务报告在 1440×1000 与 1280×900 视窗下，工作明细、当前阻塞、下一步、证据对照和前置关系均在首屏。1440px 下主体高度的实际对照：

| 样例 | 上一版 | 本原型 |
| --- | ---: | ---: |
| 执行简报 | 1424px | 907px |
| 进度分析 | 751px | 748px |
| 方案比较 | 606px | 780px |
| 机制图解 | 738px | 1165px |

**不宣称所有页面更短。** 比较页增加了直接可对照的矩阵/时间表示，机制页增加两幅分支时序；目标是对象相邻、主次明确与可比较性，不是统一减少高度。移动端的全图适配仍可能让长图字号较小，可切原尺寸或查看文字关系；不把“不溢出”冒充所有尺寸的最佳可读性。

测试是工程/浏览器证据与当前 Agent 的视觉核对，不是独立真人审美测量，也不替 Owner 作出风格认可。
