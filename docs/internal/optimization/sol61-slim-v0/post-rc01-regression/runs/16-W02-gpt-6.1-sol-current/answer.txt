控制边界应划在“规则已经确定”与“规则仍需判断或授权”之间。当前可以固定执行流程，但不能把跨地区例外的适用判断也固化成填字段。

- **固定税率计算和格式校验由程序控制。** 按已签字的税率表执行确定性计算、字段检查和格式校验；计税基础、精度、舍入方式等会改变金额的规则也须明确。缺少规则或必要输入时停止该笔自动计算，不能让 Agent 补猜。
- **跨地区例外由 Agent 辅助分析。** Agent 可以整理地区事实、检索已有条款、比较候选条款及适用证据，标明冲突和缺口。但适用条件尚未达成一致，这是规则内容未决，不能靠固定流程或“只填字段”解决，也不能让 Agent 自行形成具有约束力的政策。
- **未决规则交给有权确认的人。** 本次需要确认的是例外的适用条件、条款冲突时的优先关系及生效范围。相关案例在确认前进入待决分支，暂不进入最终金额确认或开票；明确规则覆盖的普通案例可以继续自动处理。
- **证据约束整个链条。** 保留税率表版本及签字记录、案例事实来源、条款依据和例外确认记录。格式校验通过只证明字段合规，不证明条款选对。

规则达成一致后，再把明确的适用条件、优先关系和边界情况编入程序。只有完整输入能唯一确定适用条款及金额、未知情况会明确转入待决分支时，“Agent 只填字段”才成立。不能把尚未解决的判断藏进“适用条款”字段，让下游默认它已经正确。
