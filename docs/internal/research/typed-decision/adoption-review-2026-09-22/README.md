## 评审怎样进行

三位AI在独立上下文中并行只读评审，分别负责证据、合同用途、设计与投入价值。
他们此前参与过翻译、设计或审阅，因此这是职责分离的复议，不是真人、跨模型或完全
未接触项目的盲审。主代理核对原记录并作最终裁决；不是用三票一致替代事实。

- [证据意见](evidence-review.md)：停止通用路由调题，建议先核对失败的下游后果。
- [合同意见](contract-review.md)：停止通用入口；仅在有真实重复用途时考虑一次窄任务筛选。
- [投入意见](value-review.md)：当前两用途不再分配实验资源，一次收尾后归档。

共同点：当前无采用资格，不优先修J2，不能由现有负面证据推导Jev普遍无能。
分歧：是否值得再做一个局部用途筛选。最终采用更节制的建议：**当前不做**。
现有证据未给出真实重复用途及可核对的基线损失，不能为留下Jev临时造一个新用途。

所有结果都未实际消费；下表的风险/代价是根据控制路径可推导的影响，**不是已观测的
最终任务损失**。没有最终产物，不能补写成功或失败故事。

| 场景 | 已观察差异 | 对采用决定的含义 |
|---|---|---|
| L09中文 / L11英文 | 补信息，未进入SRA | 可能多一次澄清；是否必要未有最终任务对照 |
| L14/L15英文 | 直接处理，标签为EDSP | 方法必要性有解释空间；不能直接等同任务失败 |
| L18两语言 | 直接处理，标签为SELA | 有漏掉方向判断的可能，未观测最终质量后果 |
| L19中文 | 选择SELA，标签为MPG | 明确的canonical边界偏离，可能重开已确定方向；不是已测下游损失 |
| L22两语言 | J2 present阻断，未调用owner | 候选过度阻断；当前义务/被分析缺陷混淆未证明 |

因此它们不足以为下一轮总路由调参建立优先投入理由。

## 什么证据才值得重开

重新启动须来自一个具名的新依据：真实原路径有可观察的重复性损失，或新引擎版本
带来与已知失败直接相关的能力证据。仅“再修一句提示词”“多跑几题”“换英文”不够。

启动前必须能写清：一个窄的真实判断、重复频率和基线负担、可稳定裁定的正确标准、
允许Jev改变的具体分支、以及把设计/翻译/回退/维护算入后的收益假设。没有就继续归档。
若满足，另立一个有预算与止损的试点；保持开发有限修订、holdout一次、以后正式A/B/C
与最终任务全成本验证的顺序。本裁决不启动它，也不授予未来自动执行资格。

本轮裁决后新增实验预算为0；不再新造案例、修改prompt或扩大平台。普通的源码保存和
安全维护可以继续，不能以维护名义恢复语义调参。重启条件明确前，当前用途保持停止。
