## Interpretation and limits

D09 also permits a plausible direct-synthesis reading: the supplied operating rule
already specifies the content needed for the short instruction. The canonical entry
contract discourages process weight for clear, low-risk tasks; TVG admits bounded
artifact value repair. Author labels do not resolve every overlap between those rules.
The result is a failure against the frozen protocol, not proof of an inherent Jev
limitation or of an objectively necessary TVG intervention.

Changing the label after observing it, removing D09, testing only the eight successful
cases, or asking a different serving path for a preferred answer would not validate
this experiment. A future proposal would need a new independently justified task
boundary and new evidence; it cannot be called a second revision of this campaign.
