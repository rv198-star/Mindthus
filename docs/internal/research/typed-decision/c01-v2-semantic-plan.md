# C01-v2 Chinese semantic development

## Core

Test whether the corrected contract separates close entry/owner boundaries in Chinese.
This stage qualifies neither native host execution nor net value. Full A/B/C comes after
development stabilizes and a separate holdout has been frozen and evaluated once.

## Mainline

Development contains 26 newly authored synthetic Chinese cases in 13 paired families.
The pairs vary an action-changing condition: common resource contention, decision facts,
carrier exposure, controller mismatch, artifact value need, structural uncertainty,
task decomposition, durable Mission state, explicit applicability, evidence ceiling,
option coverage, snapshot freshness, and repeated repair with/without new evidence. All members of each family remain in development.

Labels were authored from canonical contracts before live observations, separately from
the tested engine. They are author judgments, not independent human adjudication. Expected
owner in the explicit-method negative case is the constrained candidate `wae`, with
applicability `no` and final fallback; it is not an endorsement of that owner.

Only each case's `context` and the relevant runtime contracts may be sent to the provider.
Exclude expected labels, rationale, case IDs/family descriptions and sibling cases from
semantic State. The provenance reference may identify the case but supplies no answer.
Treat the synthetic facts as scenario assumptions, not real company or user records.

### Frozen development acceptance

- All 26 mechanical D0 expectations must hold; stale input must trigger zero calls.
- On the 25 semantic inputs, exact entry-mode match must be at least 23/25, and exact
  final route must be at least 23/25. Report every mismatch and abstention, not only accepted routes.
- For the 12 cases with an expected selected owner, report owner correctness and applicability separately,
  including explicit binding versus model selection. No hard-judgment case may be silently
  sent to direct execution; premature fallback still counts against coverage.
- Zero unauthorized consumption, erased known obligation, forced owner on no-match, or
  explicit-method prerequisite waiver. Any such event stops and attributes the defect.
- Report per-family pair consistency, provider status failures, no-match coverage, false
  interventions, and total calls/time/tokens/cost with unknown telemetry left unknown.
- Scores describe this small development set only; they are not statistical noninferiority
  or a generalized quality claim. No confidence threshold grants execution.

Official TypeSafe serving is primary. OpenRouter is a separate backup/serving-consistency
trial; failure cannot silently substitute its results into the primary table. Preserve
configured and resolved runtime identity, original calls, and technical failures.

One bounded semantic revision is allowed after the first development review. Name the
observed failure class, change only the relevant question/rubric, retain parent identity
and original data/labels, rerun under a new frozen contract. Do not tune the labels or
keep revising until scores pass. If another semantic change is needed, stop or narrow.

After development, author and freeze independent holdout situations/templates, their
labels and quality/cost/call thresholds. Do not use paraphrases of these paired families
as a purported independent split. Holdout gets one acceptance run and no semantic tuning.
Only then preregister A=current non-Jev, B=same graph ordinary LLM, C=same graph Jev with
matched downstream executor, evaluator, host and complete cost accounting.

## Boundary before live execution

Local engineering execution is complete separately. The current Session/CLI remains
offline-only and deliberately rejects live providers. Live work requires a small admitted
carrier with frozen egress and cumulative campaign limits; setting `is_live=False` on a
real backend or relabeling real responses as fixtures is not an admissible workaround.

The authorized intended serving path is known, but a local secret-safe credential delivery
path and a numeric campaign spend cap are not yet available. The encrypted official note
was located by metadata only; no plaintext key was retrieved, logged, copied or committed.
Freeze money/call/time limits before calling the model. Until the local carrier and these
inputs are ready, semantic status remains `not_run`, revision use remains 0, holdout remains
unfrozen, and A/B/C and #212 remain unstarted.
