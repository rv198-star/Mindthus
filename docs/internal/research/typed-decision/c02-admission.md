# C02 admission decision — 2026-09-22

## Core

Admit a separate, bounded C02 experiment after C01's stop decision. The hypothesis is
that a typed local judgment can select a useful transformation inside an already
active TVG loop and avoid an unnecessary rewrite of an adequate module. This is not
another attempt to classify D09's entry route.

## Independent standards and scope

Two low-risk synthetic text purposes are admitted: an operating instruction and a
design explanation. Independent scenario rules specify the action branches for the
first and the trade-off/limitation for the second. The flawed text is not the source of
the target or a fact source. Synthetic facts are assumptions, not real operational
evidence. No production document, release or external action is changed.

Development must cover thin, adequate, missing evidence, redundant with a critical
boundary, conflicting standards and outside-TVG objects in both purposes. Labels are
preauthored LLM judgments, not independent human adjudication. No C01 case or label is
reused. A separately frozen holdout follows only if development is stable; A/B/C
follows only after that gate.

## Bounded investment and stop rule

First deliver only the specific graph, local context construction, one-rewrite handoff
and recheck using the current journal. No designer service, generic graph interpreter
or new Provider architecture. The LLM-authored local question contract is a frozen
artifact; its design work is recorded separately and never called free.

No inference is admitted by this document alone. Freeze cases, contract, independent
labels, exact serving/model configuration, projected request hashes, thresholds and a
separate cumulative budget before calls. One semantic revision at most, no repeat-to-pass,
one holdout acceptance. Full cost gaps remain unknown and prevent a savings claim.
If standards cannot stay independent, evidence must be invented, a second semantic
revision is needed, or cost/extra review destroys the value hypothesis, stop or narrow.
