# C02 bounded Chinese experiment protocol v1

## Core

Test one local transformation inside an active TVG loop, not TVG activation. The
question contract is LLM-designed from independent synthetic standards and frozen
before calls. It contains no model/provider names. Original TVG exit authority stays
with the host agent. No production adoption is authorized.

## Sequence and acceptance

1. Offline verify the specific C02 graph and existing shared runtime.
2. Freeze 12 development cases across instruction/design purposes and six categories
   each: thin, adequate, missing evidence, redundant, conflicting targets, outside scope.
   Evaluate J1 utility and J2 source support together, then a dependent J3 action Choice.
   Labels, rationales and case categories never enter semantic State.
3. Development requires at least 11/12 exact route matches, 11/12 utility matches, all
   six expected action selections, and no rewrite for missing evidence, conflicting
   targets or outside scope. Report every row, abstention and unobserved item. A service
   or malformed-response failure stops the run. Confidence never relaxes these rules.
4. For selected local rewrite candidates, the host LLM performs one actual rewrite
   using only the selected action, independent target/evidence and the original module.
   Persist a generation intent before it starts; unresolved generation is not retried.
   Recheck utility/support together on the new artifact, then the original exit owner
   reviews fidelity and downstream use. A recheck never writes TVG freeze/PASS.
5. A rewrite may not invent facts, delete a material limit, or alter the target. A
   reference-driven reader exercise must recover the required action branches or the
   choice/reason/limitation from each rewritten text. This is separately recorded host
   judgment against a fixed reference, not a Jev self-score or independent human audit.
6. At most one bounded development semantic revision is allowed. Name the defect,
   preserve original cases/labels and prior calls, freeze the new contract. Stop/narrow
   if another revision would be needed. Do not revise targets to fit observations.
7. Only after development is stable, author and freeze independent holdout situations
   and references. No paraphrases of booking/exhibit development examples. One holdout
   acceptance, no tuning. Thresholds and budgets must be frozen before that run.
8. Only after holdout may a matched A/B/C comparison be frozen: A original TVG, B this
   graph with ordinary LLM decisions, C this graph with Jev decisions. Identical
   downstream generator/evaluator configuration, evidence and rewrite budgets for B/C;
   A retains its original semantics. Ordinary-LLM serving and full comparison ceilings
   must be separately bound before calls.

## Cost and stopping

Initial development planning: official TypeSafe `jev-1.13.0`, at most 24 calls, 120
inference seconds, 98304 request bytes, reserve USD 0.002688 per attempted call.
The entire C02 development series (original, any bounded revision, generation/recheck
and diagnostics) has a USD 0.25 Jev inference ceiling. No hidden retries or ad hoc
diagnostics. Every later stage inherits spent/reserved amounts from original journals.
Generation/audit by this Codex host has unavailable token/price telemetry: record it as
unknown, including one-time design and context/review work. It is not part of the Jev
price estimate and cannot be presented as zero cost or a proved saving.

Future comparison is admissible only if it can measure matched downstream outcomes
and account for all cost channels. Require zero material fidelity/authority errors,
no loss on the preregistered downstream reference tasks, and at least 20% reduction in
measured repeated-use total model cost for a positive saving recommendation. One-time
design/validation remains separate; show cold-start and actual-count amortization.
Unknown required cost prevents a positive economic conclusion. No invented reuse count.

This small synthetic series cannot establish broad quality noninferiority. Permitted
outcomes are keep original TVG, narrow, stop or evidence insufficient. Do not build a
telemetry platform, generic designer or extra audit loop merely to rescue this pilot.

## Evidence ownership

`c02-independent-standards.json` contains independently declared scenario assumptions;
`c02-zh-development.json` contains flawed/adequate artifacts and separate author labels;
`c02-local-contract.json` contains the host-LLM's L0 design. Record design cost as unknown,
not as an API call that never happened. Mechanical source/identity checks do not certify
target quality. Development, holdout and value qualification have separate conclusions.
