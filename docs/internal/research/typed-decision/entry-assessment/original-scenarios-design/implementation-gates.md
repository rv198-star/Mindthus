# 实施前剩余关口与复审处置

当前：设计v0.2已形成，两轮四份真实模型审计均返回REVISE。完成本次设计/审计交付，不等于设计获全项通过。这里是作者对复审意见的归因与待办，不是第三轮审计，也不覆盖原始评审。

## G1：把主判断交付写成有区分力的合同（D1冻结前）

保留v0.2的verdict_delivery和definition_delivery分工，补三个固定候选的完整判定例：有主结论并有必要限定；只有载体等同说法并在末尾列其他观点；纯罗列而无承诺。判断依据是实际承诺、材料支撑、同对象控制关系及决定后果，不是“第一句包含什么词”。

Skills定义类frame有既有候选时，definition_delivery必须进入该frame的消费集合，不可因Q1s已接受范围就跳过。输出应能定位候选中实际承担主结论、控制关系和关键区分的文本引用；无对应内容记missing/uncertain。无需让Jev自由生成引用哈希；由宿主给有界片段选项、代码验片段、模型判关系。原始引用列表不够时返回原owner，不能硬填更丰富解释。

有证据证明prompt机制足以解释所讨论的具体实现时允许该结论；“移除某机制会失败”至多证明必要性，不自动证明足以定义整个对象。因此不接受审计建议中将某种反对结论或单一反事实测试设为固定正确答案。

## G2：多个决定因素的组合与不确定出口（D1冻结前）

保留同一frame可有多个decision_driver，禁止按票数/最高概率选一个。补共同关系表达的判例：多个事实联合决定一个明确结论；不同用户取舍对应不同条件结论；已给材料无法确定关系。最后一类明确返回原owner或输出有界条件判断，不重回Q0/Q1递归增加模型调用。

driver应说明改变该事实/条件会对当前决定产生什么具体后果，避免只是“相关”。但复杂系统中的冗余因素或共同必要因素不一定满足“单独反转就翻转结论”，不能把审计建议的单一反事实要求硬编码为通用因果定义。counterfactual只作为有依据时的判断支撑。

原责任LLM继续完成最终判断是canonical设计，不因它与候选作者相同就被认定为非法自证；必须计入可能重复犯错的风险，并由端到端独立评估验证。Jev与LLM的结果均不是独立事实。

## G3：把工程表和验收判例锁定（D2/D3冻结前）

明确计数单位：一次provider request是一批，一批内可有多个问题实例；并行题、调用数和秒数分别计数。v0.2的22实例/24上限与最多7次新增请求不是同一单位。

拟议字段映射（待离线实现测试，不是现有字段已经存在）：

| 新profile字段 | 拟议上限 | 现有接入点 |
| --- | --- | --- |
| judgments_total | 4 provider requests / episode | CHECK_LIMITS与Session；再加episode总账限制 |
| corrections_total | 2 / episode，1 / turn | _correct的intent/outcome和单次hook |
| structural_organize | 1 / episode | 单独有界host步骤，计费计时，不藏在输入准备 |
| total_requests | 7 / episode | 新模式不可变预算profile，替换旧BUDGET，不与旧Jev路由叠加 |
| request_seconds | 累计120秒 | _elapsed/_remaining读取新mode全部结果 |
| single_call_seconds | 45秒 | 已有有界HTTP/host超时；超时不是自动重试许可 |
| questions_per_batch | 最多24；当前容量表上限22 | 实例化器与请求预算 |

预算耗尽后，新用户原文/新证据按原样交原host，插件记录fallback事件而不新建Jev intent；原host自己的调用照其原日志记录，进入端到端账单，不纳入已终止的插件额度，更不能假称免费。

## 不采纳为新增阻塞的评审要求

- “Q0可能错，所以违反证据分层”：不成立。它是基于原文的模型核对，不是事实认证；保留误映射测试与原文端到端评估，不声称它无盲区。复制一次提取或让模型生成哈希不能消除风险。
- “同批条件题依赖未产生的Q1，所以必须拆请求”：条件输入已提供，按canonical及官方fan-out可投机执行；成本和未消费项已经明确记录。
- “多条driver等于多个主判断owner”：不成立。事实因素和职责owner不是同一概念；按G2明确联合/条件结论。
- “小样本不能报告任何改善比例”：可以描述固定样本内的配对计数，但不能从中宣称分布上优于基线；全体退化/未知/费用必须同列。自动采用一直未授权。
- “必须keyword识别原文才能证明映射正确”：关键词不足以证明语义关系；字面引用由代码检验，语义覆盖仍需模型与独立结果评估。

## 决议

本轮停止于实施前设计关口，保留v0.2及全部审计。允许继续完善G1/G2的离线声明式判例与G3字段映射，不把它们称为已通过复审；在其未关闭前不冻结D1模型题文。付费场景试验、实际默认入口与生产均不准入。没有开启第三轮审计，没有改运行源码，没有重跑Skills/4K或旧6/8例。

研究计划仍以原始Skills多轮和4K处境判断为主，不退回单独修P3或新增通用题库。#211保持OPEN。
