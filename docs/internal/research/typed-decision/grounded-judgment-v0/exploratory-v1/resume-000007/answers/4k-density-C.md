# 4k-density-C — actual raw products

## First draft

针对你的目标，现有27寸4K面板无法靠设置或BetterDisplay达到同尺寸5K的物理像素密度。按常见的3840×2160和5120×2880计算，两者约为163和218 PPI；物理像素数量由面板决定。要在27寸达到后者，需要更换为相应像素密度的屏幕。

争论中，MikeZTM关于软件不能改变PPI的判断成立，但“任何软件都没用、只会更模糊”说得过满：软件仍可能改善界面大小和缩放体验，只是不能增加物理像素。原帖所称“设1440会影响性能，所以只能用5K”，对你的物理PPI目标而言，换屏方向是对的；其中性能影响的程度，以及缩放体验是否可接受，缺少具体设置和实测，不能确认。
