**维持与改变的判断**

1. **C01-R26：TVG 可用，不足以证明直接执行必错。**

   三层结论须分开：

   - **Canonical 可接受性：**我接受标签评审的 `{direct, intervention}` 争议集合。TVG 明确支持有边界的用途修复，同时排除低风险工作的无益流程负担。案例已经给出完整操作规范，直接合成一个可用段落有充分理由。我初审证明的是 TVG 有依据，未证明其必要性。
   - **具体 2.1 合同一致性：**`c01-semantic-r1.py:125–128` 明确把“既有产物、命名用途缺陷、独立目标、非完全规定编辑”纳入 intervention。R26 符合这个更窄的实验约定，观测 direct 与该约定仍不一致。不能用 canonical 的宽容集合抹掉具体合同服从性问题。
   - **实际任务价值：**完全未知。没有观察直接改写与 TVG 改写的质量、时间或成本。即使模型正确服从 2.1，也不能证明这次介入值得；即使直接改写完成得好，也不能反推它遵守了 2.1。

   所以 C01 停止原资格流程应维持：修订已用尽，冻结停止条件已触发。但“客观必需 TVG 被错误漏掉”不成立。作者 `c01-v2-disposition.md` 已明确承认这一点，我同意其限定。

2. **C02 冗余文本可以已经可用，同时存在压缩收益。**

   R03/R09 的理由、分支、限制已经存在。作者将二者固定为 deficit，缺少“冗余达到何种程度构成有意义缺陷”的独立标准；模型 adequate 可辩护。

   但合同自身也有张力：adequate 选项不只是“达到用途下限”，还写了“no meaningful local value deficit”；action 又允许 compact_preserve。若压缩收益是显著的，adequate 与 compact 的组合需要解释；若只是可有可无的轻微改善，则 leave_unchanged 同样合理。不能一边用 adequate 表示“没有有意义缺陷”，一边将必要重写解释为完全一致。

   因而原 utility 唯一标签不宜当真理；compact 标签可以用于“动作是否适合此文本”的窄测试，却不能单独验证“值得执行这次动作”。R06/R07 的明确缺口、R02/R08 的完整文本，仍是比较扎实的对照。

3. **R02 的 adequate→make_actionable 是局部选择不一致，不能归因为实际改坏了文本。**

   R02 已明确空闲、占用、禁止覆盖，沒有指出剩余行动障碍；合同要求无实质收益时 leave_unchanged。故 make_actionable 不仅与作者标签不匹配，也缺少可见任务依据。

   可同时成立的三个观察是：

   - 引擎在此选了缺乏支持的动作；
   - action 选项描述偏重“适合哪类文本”，可能诱导选择相关类型而非必要变换；
   - runtime 接受了 adequate 后的 rewrite，未处理语义冲突。

   现有一次记录不能分离各因素贡献，更不能断定“多一次判断必然造成错误”。最终生成可能不改变文本，也可能浪费工作；没有实际生成，不能宣称已发生后果。作者“would cause an unnecessary rewrite”宜精确为“已提出无明确增益依据的 rewrite_candidate；若照此消费，会触发生成”。

4. **修正我对 support 重检缺口的系统级归因。**

   我维持：来源充分性问题不能可靠检出成品新增无来源断言或删除重要限制；新成品改变而来源、目标不变，support 仍可正确回答 sufficient。`c02.py:174` 将“读取 artifact”直接当作“该语义判断受 artifact 变化影响”，理由不足。

   但新读到 `c02-protocol.md` 第4、5步：原退出 owner 另审 fidelity 和 downstream use。由此不能断言整个流程没有成品忠实性审计。且本轮没有真实改写、没有执行重检，这个缺口**不是本轮失败的已观察原因**，只能限制“重检 support 已验证成品忠实性”的资格声明。作者没有作该声明。

5. **utility→action 是可接受门控；必须串行及其净收益尚未建立。**

   scope/conflict/unclear 防止不该发生的改写，具有真实用途。不能仅因 action 重读原 State 就称 utility 是制造调用。

   不过当前传入只有标签，未改变候选集、证据或 rubric；action 可能在同 State 下投机计算后再由门控决定消费。哪种更好，须比较串行、同 State 合批，以及缺省/错误前序标签的消融。现有结果只证明门控确实改变路线，未证明串行最优，也未证明标签能改善动作选择。

**停止范围、剩余修订与作者勘误**

- **维持 C01 原资格停止。**不能追加第二次修订继续称原活动验收。独立重审标签可以追加，但须保留原分数与失败；其结果是补充解释，不是原协议转通过。
- **维持 C02 当前合同/数据对的资格停止，允许复议研究投资。**0/1 是可用上限，不强迫消费。一次修订可以合法澄清“相关变换≠值得变换”、来源缺失≠目标冲突，前提是不改案例、标签、阈值，并冻结版本。可是它无法修复独立标签依据薄弱的问题；把所有重复强行定义为 deficit 更不合法。因而“不马上花掉修订”是合理投资决定，并非预算耗尽的机械必然。
