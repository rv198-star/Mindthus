# ③ Jev direct — complete-source input

Owner approved a new direct-Jev comparison and required the original user request plus complete SKILLS and methodology descriptions. This is a distinct architecture from closed ② mixed control; its negative evidence stays intact at 83dfa80.

## Input and responsibilities

The default corpus includes every `skills/*/SKILL.md` in full (including using-mindthus and explicit-only case-prep), plus every Markdown file under `docs/methodologies/`, including cognitive primitives. A separate, explicitly named full-resource profile additionally includes every Markdown resource under `skills/`. Neither profile is a selected candidate subset. Scripts, binaries and historical experiment/review reports are outside the descriptive-corpus scope. No file is silently cut, paraphrased, translated, deduplicated by meaning, or replaced with a model summary. A manifest binds exact UTF-8 bytes, paths and revision.

Actual user messages and supplied evidence retain order, source, authorship, authority and missing-source limitations. No LLM-generated frame or shortlisted candidate enters S0. Corpus assembly is deterministic. The inclusion of an entry/helper document as reference does not make it an automatic execution target.

Jev is the first semantic processor of the task. It should evaluate the full method inventory with Noul, Choice and Score for applicability, roles/relationships and intensity, together with relevant cognitive obligations. The host then receives the original task and selected complete method material/obligations; it does not first load the using-mindthus entry to select candidates. Support for multiple methods remains. Jev does not grant permission, certify facts, or infer missing original screenshots. Read-only file loading is not proof of native plugin dispatch.

## Capacity — verify, never disguise truncation

Official documentation checked on 2026-09-27 (`https://docs.typesafe.ai/models`) states 64k tokens per request and 32k tokens for State plus its longest question. Byte length is not a token count. The existing local provider has a separate 256 KiB request-byte ceiling. Those old transports and freezes remain unchanged.

Prepare the complete corpus first. At most ONE separately journaled official capacity probe is authorized within this preparation task: complete entry/methodology corpus, the original E first user request, and three typed questions. It is a capacity probe, not a scored routing trial or proof of quality. Its diagnostic transport has an explicit 2 MiB request cap, fixed official endpoint/model, no redirect, no automatic retry and no saved key. HTTP response, capacity error, actual model and usage are recorded. A larger local byte budget is not claimed to enlarge the supplier token budget.

If a single State cannot fit, retain the full corpus and record that limit. A lossless per-method parallel-reading protocol is a distinct proposed protocol: every complete method packet is read, shared cognitive constraints retained, and complete relevant source is reintroduced for cross-method decisions. It must never be reported as all sources co-visible in one State. Do not silently switch to that protocol or discard files to make the run pass.

③ is a new arm, not retrospective repair of ②. Matched comparisons must count all preparation, Jev, host, correction and review costs. No caller should consume three capacity-probe judgments as a completed router. Ordinary direct answering, factual acquisition and scoped disagreement remain available. Low method confidence is not a blanket answer veto.
