决定如何穿过路径。\n\n对外解释时，应把“长期方向是否成立”和“当前载体是否值得继续”分开说清。只有没有载体、\n路径或行动承诺需要判断时，才停在方向层；不能从“方向可能正确”直接推出“当前载体必须\n继续”。Agent 的 direct-load、companion skill 加载与输出形状要求属于\n[`SELA runtime surface`](../../skills/sela/SKILL.md)，不由这份公共方法文档承担。\n\n## 怎么用\n\n使用 SELA 时，不要先问“我喜不喜欢新方案”，而是按顺序问：\n\n1. 旧方案的局部优势是什么？它是真优势、偏好、路径依赖，还是身份认同？\n2. 新方案的系统效率来自哪里？速度、成本、分发、反馈、复用、规模还是组合能力？\n3. 这个效率差距是否会随时间扩大？扩大速度是否超过旧方案的改良速度？\n4. 旧方案能不能把自己的局部优势系统化？如果不能，它会退到哪个边界？\n5. 做一次单 Agent 多角色压力：`System Advocate` 讲系统效率，`Local Defender` 讲局部价值和硬边界，`Timing Auditor` 判断当前行动窗口。\n6. 当前行动窗口是什么？现在该全量切换、试点、保留双轨，还是等待关键证据？\n\n输出不必复杂。多数情况下，一句判断加一个动作就够：\n\n- `commit`：方向清楚，风险可控，继续保留旧路径会锁死未来。\n- `trial`：方向有压力，但仍需要小规模验证和真实反馈。\n- `hold`：旧方案仍承担关键价值，暂时保留，但继续观察系统差距。\n- `wait`：证据不足，切换成本高，过早行动会制造不可逆损失。\n\n默认不拆成多个 Agent。SELA 先用单 Agent 多角色避免效率判断自我强化；只有在高影响、强分歧、长期方向或路径依赖很强时，才升级为多 Agent 对抗。\n\n## 具体案例\n\n### 案例 A：专家手写代码 vs AI 辅助开发\n\n一个资深工程师手写代码的局部质量可能仍然高于平均 AI 输出，这个局部优势是真实的。但如果 AI 辅助开发能把搜索、样板代码、测试补全、文档同步和小修复的成本持续压低，团队整体吞吐可能会被系统效率重写。\n\nSELA 不会直接说“立刻全员放弃手写”。更合理的判断是：长期主战场会向 AI 辅助系统迁移；当前动作可以是 `trial` 或局部 `commit`，同时保留专家 review 和高风险模块的人类判断。\n\n### 案例 B：人工客服 vs 看，现代医学（通常被称为现代西医）的系统级优势更强：可重复的诊断体系、临床试验、影像和检验、药物研发、外科与急救、公共卫生、标准化指南、监管体系和大规模医学教育。这些能力会持续扩大系统级费效比差距，使现代医学长期占据主战场。\n\n更合理的判断不是“中医立刻消失”，而是：传统中医更可能保留在文化信任、辅助调养、康复体验、生活方式管理和少数经证据验证的细分场景；凡是急症、感染、肿瘤、外伤、妊娠、儿童、高风险慢病和不可逆伤害场景，都不应让局部经验压过现代医学证据和安全边界。\n\n## 常见误用\n\n最常见的误用，是把 SELA 写成“效率一定赢”。这会把方法变成浅薄口号，也会破坏它真正有用的部分。\n\n另一个误用，是拿长期趋势直接推出短期动作。长期看系统方案更强，不代表今天就应该关闭旧流程、废弃专家判断或牺牲过渡期质量。SELA 应该同时保护方向判断和时机判断。\n\n还有一种误用，是把局部优势贬低成“落后”。这也不对。局部优势往往是系统方案学习的源头，尤其在审美、风险、伦理、复杂上下文和高价值例外场景里，它可能仍然是校准系统的关键输入。\n\n## 边界\n\nSELA 解决什么问题\n\n很多资源浪费并不是因为正在做的事情完全没价值，而是因为它仍然“可以继续变好”。\n\n例如一个页面已经达到上线门槛，动画还能继续优化；但支付链路尚未验证。继续做动画并不错误，\n只是它已经不再决定本轮目标能否成立。如果没有一次明确的资源判断，当前任务会因为已经打开、\n已经投入、继续起来最顺手，而不断获得更多时间。\n\nSRA 处理的就是这种竞争：\n\n- 当前任务继续做，还是切到更关键的任务；\n- 新发现的问题现在修，还是记入后续；\n- 多个产品问题谁进入当前 Sprint；\n- 故障、合规、技术债和新功能怎样争夺团队资源；\n- 现金有限时，完整建设和方向验证之间如何取舍；\n- 一个人同时承担多个长期项目时，哪些主攻、保底或停止。\n\nSRA 的判断中心不是“哪个任务听起来更重要”，而是：\n\n> 哪些候选真正竞争同一种有限资源，它们如何影响同一个目标门槛，当前下一批资源投到哪里最合理。\n\n## 核心判断\n\n主路径只有三步：\n\n1. **保住目标成立的必要投入**：先明确目标、时间范围、权限和不可突破的风险底线，再找出足够支撑目标的最小可行投入。\n2. **把新增资源投到最值得的地方**：在可行用途之间，比较下一份有意义投入的风险调整后边际价值。方向验证、瓶颈、窗口和信息只是价值来源，不是天然更高的优先级标签。\n3. **不为填满资源而投入**：保留有理由的维护与机动量，明确延后或停止，并说明何时重新排序。\n\n“先生存、再图强”不把原本目标偷偷降低为勉强生存，也不让必要项无限占用资源。收益不只指短期财务回报：维护、学习、照护、长期能力和选择权可以有重要价值；难量化和未知都不等于零。安全、尊严和已承诺的责任先界定可行范围，不能靠较高收益比买断。SRA
