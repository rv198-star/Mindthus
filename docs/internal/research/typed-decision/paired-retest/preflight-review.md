# 推理前复核

主代理汇总两位此前参与过本项目的AI只读意见；不是逐字纪要、盲标或真人评审。
review_labels在新结果前复核原gold；review_contract检查公平性、状态映射与资格边界。

采纳的修正：

- 30语义题全部报告，并预先单列22题敏感性口径；L09–L12、L14、L15、L17、L18
  的信息充分性/方法必要性存在争议，不能只排除旧结果不匹配者；旧gold均保留。
- 技术失败碰巧得到正确fallback不计对。最终route/owner对不能拼接不同允许答案。
- 状态、中间路径、调用数及回退原因都保留，最终分支对匹配不代表任务完成或实际加载。
- B的abstain/missing_context出口与Jev的unclear不是同一适配机制；比较对象明确为
  模型/适配组合，不要求confidence数值相同，不把全部差异归为模型参数。
- 两臂进入下游的样本会不同，不为凑齐节点表在本轮临时强制执行下游。
- A需真实宿主基线。现有run-judgment-benchmark-cli.py面向Codex CLI/插件行为，
  不能用新造单次Chat提示词替代它再标成原Mindthus。

本轮不修合同，以免同改实验与题目后无法归因。一次对照完成后作一次处置，不自动
启动循环。现有工程通过与下面离线载体测试都不是语义资格证据。
