# C01 同图 B/C 开发对照 v1

用户于 2026-09-22 授权重新设计重测。核心问题：固定图与判断标准时，普通 LLM 与 Jev
的最终路由表现是否不同？本轮不修改图/问题，不优化到通过，不启动 C02。

## 比较与范围

- B：现有 ChatProvider，OpenRouter `anthropic/claude-sonnet-4.6`，固定 Anthropic
  serving、禁止服务商回退；temperature 0、max_tokens 2048，原结构化输出协议。
- C：现有 TypeSafeJevProvider，官方 `jev-1.13.0`，已验证的 Choice 舍入兼容。
- 两臂使用同一 C01 graph 3.1、相同英文 case State、完整英文 canonical 与问题。
  适配器的输出形式不同：B 可报告 abstain/missing_context，C 可选 unclear；保留原
  映射，不伪造相同概率。因此比较单位是固定引擎与适配器组合，不是孤立模型参数。
- 所有32个既有语言诊断开发场景：30个语义场景、2个D0机械场景。一次全新运行，
  不把旧Jev记录混成同期样本；这是用户授权的新比较，不是重跑旧终止trial。
  英文是两臂共同执行视图，结果不证明中文能力或在线翻译收益。
- 按L01至L32，奇数场景先B后C，偶数先C后B；无重试。各臂实际model/provider首次
  成功后全试验锁定，不因每场景一个Session而重置。每场景最多3次调用/每臂60秒。
- 全部可能owner路径的请求哈希预先登记，不用gold筛选请求。输入不含gold/rationale。

## 冻结的主次指标

1. 主指标：30语义场景中，技术有效且最终 `(route,owner)` 完整对属于原允许集合的
   数量/30。entry另评；不能把不同允许答案的字段拼起来计对。
2. 次指标：原 `(entry_mode,route,owner)` 联合匹配、各节点观测、回退原因、明确调用
   约束、错误owner、弃权/覆盖及技术失败。显式绑定不计Jev/LLM选中owner。
3. 敏感性：固定排除 L09–L12、L14、L15、L17、L18，另报22语义场景。同一口径双臂
   同时报告；原标签不改，L13/L16保留原多允许答案。不能按结果选有利口径。
4. 两者均匹配、仅B匹配、仅C匹配、均不匹配逐题公开。不把微小样本差异称显著优势；
   两种口径方向翻转或差异不清，结论为未决。题目家族相关，不能当30次独立随机抽样。
5. 技术失败绝不计正确；语义弃权按原合法分支评分，同时单列其状态和原因。D0单列。
   主指标名称仅为“最终分支对匹配”，不是实际技能加载、任务质量或生产正确率。
6. 各节点只有两臂真正执行且State/Question相同才做配对观察；上游筛选导致的未调用
   不算对错，不在本轮临时强制补节点。全部记录consumption必须为not_executed。

## 预算与停止

最多180次推理（30语义×最多3次×2臂），合计调用墙钟上限1200秒；每个HTTP请求
最多60秒。**推理支出上限USD4**；设计、翻译、宿主、评审成本未知，单独报告。
2026-09-22官方价格：Sonnet输入USD3/M、输出USD15/M；Jev输入USD0.042/M、输出免费。
来源：OpenRouter models API、https://openrouter.ai/anthropic/claude-sonnet-4.6 、
https://docs.typesafe.ai/models 。

每次发送前预留：B USD0.14（请求体≤32768字节，输入token额外512余量，输出≤2048）；
C USD0.002688（64000输入token上限）。B限定供应商与价格上限，不使用付费工具。
各场景原Session继续使用完整预留；全局账将已返回有效usage.cost的B请求记为观测成本，
未知/失败请求保留全额预留，C保持全额预留。下次调用必须满足累计记账+新预留≤4。
保留累计总预留数，释放已知账款的多余预留不等于删掉历史成本。C价格估算与账单分开。
若实际cost或token超预留、身份漂移、字节超限、权限/义务丢失、未决请求或技术失败，
立即停止整批；失败计入固定计划分母并单列，余题unrun，绝不据不完整样本裁定胜负。
普通语义错误不会提前停止，否则会造成选择偏差。无技术自动恢复、无换服务商补分。

## 预先规定的解释和后续

- B胜C：支持“该引擎/适配组合在该固定图上较弱”，不证明所有路由不适合Jev。
- B/C同错：共同合同、标签或任务难度需要核对，不自动说明gold错。
- C达到/超过B：仅支持继续研究；还需保留集、真实原版A、最终产物及全成本证据。
- 两口径翻转、明显覆盖差异或样本不足：明确未决，不自动增样或改题。
