# #211 独立全流程对照 v1

用户最新指令：同一任务，不用 Jev 与使用 Jev 各自从头判断、执行、交付。2026-09-26。
本计划替代“先完成共同候选诊断才能运行独立主对照”的排序；保留所有旧原始记录。

## 主比较

每个来源启动三个相互隔离的 Codex 会话：不用 Jev、Jev①建议式、Jev②约束式。
均从原始任务和同一历史截止点开始，无共享首答、宿主推断、方法候选或 Jev 返回。
①/②也独立组织并请求 Jev，不复用请求缓存。场景仍为 E Skills / F 4K。

现有两份历史材料用于开发性全流程比较；E 缺中间助手答复，F 缺原图，所有条件同样知晓。
不声称完整复现旧失败，不输入旧修正答案、共同候选、expected_behavior 或评阅标准。
只复制 d2 sources/E.json、F.json，记录原 hash 与来源；旧结果不成为新运行的宿主输入。

固定 `gpt-6-sol`、xhigh、工具禁用、单次240秒、执行总计360秒、最多两次执行含接收；
一次修订、一次仲裁。使用已有 Runtime，不为本轮放宽路由阈值/阻断规则。
不用 Jev 可自选直接处理或方法；Jev 组使用现有 S0→执行→S1→必要修订/复查→接收。
每组可访问相同原文和完整方法正文；Jev 自身的既有 S0/S1 State 保持原实现。
Jev 组额外组织和观察是方案真实开销，单列，不伪称总模型调用数相同。
不再先跑 natural；不用 Jev 组的首次 execution 才是该组首答。

## 最小接收修复

native 回复明确 artifact_action=retain/replace；retain 绑定已有候选完整文本与 hash，
模型用空 text 表示保留，由适配器机械引用现存版本。replace 必须给完整新正文。
这是宿主传输约定，不能把任意“保留原稿”的自由文本自动解读成合法保留。
旧冻结和旧错误回执保持不动。禁止作者替实验组选择方法或代答。

## 调用与终点

六条完整路径各运行一次。新 Jev 主预算最多12次（四分支×3），不利语义结果不重试。
Codex 主执行最多36次（含准备、接收、可能异议）；匿名评阅最多6次。
运行顺序事前定：E 不用→①→②；F ②→不用→①；分支允许同时运行。
各分支自己的 session 持续 resume；仲裁单独 session。调用上限由分支 Episode 与批次预留共同约束。
不调用 CPA/OpenRouter；官方 Jev 固定 jev-1.13.0。费用暂计0，实际未知。

所有已启动分支均计入分母，包括无答案、未决、技术失败、宿主拒绝、错误交付。
主终点：最终判断和实际交付是否有效，以及不必要阻断；方法名、调用成功、形式回执不作通过依据。
E 看 Skills 范围和机制/整体价值关系，允许合理简单解释；F 看实际可用性及物理/性能边界，保留图片缺失。
评阅标准不传宿主。每来源两个独立匿名 Codex 评阅，有实质分歧补第三个；不同会话不冒充人工或跨模型。
仅评阅实际最终产物；各组差异是完整方案差异，不从多个阶段推导 Jev 模型单独准确率。

六分支完成后先报告这项主对照。原材料已暴露、只有两来源，结果不证明统计非劣。
新来源 N 和扩到 A–F 的资格按原设计；本轮不临时编造或挑选新题凑规模。
