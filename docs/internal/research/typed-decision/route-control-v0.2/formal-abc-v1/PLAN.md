# #211 三家族 A/B/C 小保留集：执行前协议

## 对照对象

HB/HC/HD 来自一次隔离上下文生成、输出中没有方法/答案标签的 [保留任务源](../formal-holdout-source-v1/RESULT.md)。三题分别属于控制边界、长期方向/当前载体、结构澄清→稀缺资源分配；这仅是 AI 合成的小保留集。三臂收到同一原始任务与给定事实，使用相同 `gpt-6-sol` Codex CLI 宿主配置、只读工具权限和独立上下文。

- A：显式原生 `$using-mindthus` 非 Jev 路径，挂载同版本技能文件。必须核对模型事件中是否实际加载 skill；仅有挂载不算使用。
- B：当前 `route-control.v0.2.1` 同图，由普通 Codex CLI LLM 回答局部题，原数值只算未校准主观值。
- C：同图由官方 TypeSafe `jev-1.13.0` 回答局部题。

B/C 路由提交后由独立 Codex CLI 宿主读完整 handoff 并返回可校验回执；路由未决时由同型号 Codex 对原任务独立回退，明确记为 `delegated_host_work`，不算②约束式消费。HD 的后继题只在原宿主审看并接受前置产物后按原账本触发；不因缺失或供应商故障重发初检。A/B/C 按相同任务逐臂留原始文本、事件、用量和耗时；不同臂不共享模型上下文。

## 事前质量与成本门槛

HB 必须锁住批准版本或内容差异，分开确定性检查、Agent 解释与负责人批准，阻断未经再审的 v5；HC 必须把长期方向和本期 3 人周/7 人周缺口分开，给秋季交付和可观察切换条件；HD 必须给出 App/网页/纸图等可比候选，再在 40 开发小时、24 编辑小时和 3000 元印刷费下给条件式资源选择。各题 `cases.json` 另锁定严重错误。一次匿名独立 Codex 评阅依据这些性质判断三臂最终产物；缺最终产物或严重错误即不可用。主要质量非劣界：C 在三题中的可用数不得少于 A，且 C 严重错误数为 0。B 与 A/C 同表比较，不调成与 Jev 相同 confidence 门槛。

主要成本改善目标：C 的**完整实际货币成本**（Jev、Codex 宿主、回退、重试及工具）须比 A 少至少 20%，且质量门通过；金额缺失则成本门为 unknown、不得宣称通过。端到端耗时和 token 分列为次要观察，不跨模型把 token 当美元。一次性设计/脚本时间另列，不摊入首批请求成本；若评估重复使用，则须另给摊销次数和证据，不能从本批推断。冷启动 A/B/C 均按实测记录。

## 固定预算与停止

三题每臂最多一次首轮任务；A 最多 3 次 Codex CLI；B 最多 3 次初始裁决、4 次宿主/回退，HD 仅在前置产物合法接受后最多再 1 次裁决；C 最多 4 次 Jev（HB/HC 各 1，HD 最多 2）与 4 次 Codex 宿主/回退。全部受测 Codex CLI 最多 15 次，匿名评阅最多 1 次；Jev 每次预留 USD 0.02，最高 USD 0.08。CPA/OpenRouter 0。供应商未知 intent 不重发，技术失败本版不自动重试，不换模型，不在看答案后改题、删题或放宽门槛。平台安全拒绝立即停止被拒动作。
