# #211 独立上下文任务候选源（执行前）

此调用只生成**候选输入**，不运行 A/B/C 受测臂，不判断期望方法或答案。
生成者是一个隔离的 Codex CLI `gpt-6-sol` 会话：不挂载 Mindthus 技能、
不提供路由图、实现、既有测试输入或作者答案。它只收到 A–F 任务形状，
一次产出九份低风险中文虚构任务，编号 A1/A2/B1/C1/D1/E1/E2/F1/F2。

候选源的独立性只指**生成上下文与实现/受测输出隔离**。AI 合成任务
不等于外部真实任务或人类独立标注；语义相似、家族覆盖和标签有效性
仍须在受测臂推理前审查。候选若不合格则记录原因并停止本版，不在
看到受测结果后改写或择优取样。

预算：最多一次 Codex CLI 生成请求，120 秒，无自动重试；新 Jev、CPA、
OpenRouter 请求均为 0。模型服务端身份、金额未知时明确为 unknown。
输入 prompt、脚本和源提交在调用前固定。输出原文、事件、请求意图和
结果原样保留，不自动成为正式 #211 保留集或放宽其质量/成本验收。
