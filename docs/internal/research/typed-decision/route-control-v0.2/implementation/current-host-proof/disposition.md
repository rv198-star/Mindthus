## 已完成

同一 `entry.run` / CLI 注册 current-agent 宿主交接，默认不构造CPA执行者，不读取其密钥。判断Provider的live属性与本地宿主传输独立；真实Jev仍须按原规则取得准入。原方法语义、19题模板、路由消费政策及DS显式使用时的max要求保持。

当前Agent接收包含真实已读方法、原始材料、路由/候选版本及作用范围的请求，返回执行结果、具名纠偏或局部异议。回执校验复用原消费者。语义仲裁要求不同宿主上下文声明，不默认让执行者自批或调用另一供应商；声明不构成对真实隔离的证明。必要产物的接受仍由原宿主提供的artifact_acceptor决定。

等待请求放在原Episode目录，预留既有角色额度但不假称已完成；恢复返回同一请求，不重跑判断、不再占一份额度。非法回执在保存前拒绝，可更正后提交；已接受回执不可覆写。原外部供应商未知intent仍不允许重发。时间不可观测时按预留上限保守记账，同时保持实际耗时unknown，费用也不填0。

## 边界和后续

本交付是具备文件/命令工具的宿主可调用的接入接口，不是为所有Agent产品完成原生插件自动安装。宿主确实读取并执行请求才能形成执行证据；仅显示一段提示仍不算强制执行。回执也不证明内在推理或最终事实正确。

当前案例与历史开发控制不升级为自然任务或全八方法资格。旧两例付费freeze保持未运行；新实现改变了implementation identity，后续在允许的执行条件下使用新准入，不能拿旧freeze静默重发。下一步是以当前Agent作宿主的真实Jev小批端到端及建议式/约束式任务比较，而不是再添加一个强制的CPA产品依赖。默认Skill、main及历史试验不改；#211继续OPEN。
