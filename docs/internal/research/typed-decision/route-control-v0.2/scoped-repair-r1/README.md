## 两项修复

1. Jev 两个 serving adapter 共用逐题解码验证。合法的 Noul/Choice/Score 保留；某题不合法时返回 answer_contract 局部失败，值不进入路由。缺题/额外题、运行型号不符、传输失败等仍按整体失败处理。Episode 不再因可选 Score 的局部失败阻断其他有效作用域。独立保存过滤密钥及私有推理字段后的解码 JSON 回执，绑定实际请求摘要；有效用量在校验失败时仍保留。它不是丢失历史响应的补造，也不是网络原始字节。
2. 某后继仍未决且其具名依赖产物已经被原宿主接受时，仅重评该后继。State 保留原始材料，并显式加入“宿主产物，仅被接受用于此用途，不是独立事实”的实际文本与接受凭据。原前置观察、执行和不相干作用域不重跑。新批次使用同一本 Episode/Session、原次数与时间上限；同一材料只生成一份可恢复记录。仍未决即返回相关范围，不循环追分。

旧原型允许一次初始路由，但没有前置完成后的重新判断接点。本次落实已有设计所允许的新状态依赖；不是通过更低门槛假定 SRA 已就绪。
