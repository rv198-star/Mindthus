# 独立审查与处置

一次真实、隔离只读Codex审查，请求gpt-6-sol/xhigh，配置的当前宿主端点为sub2api；不是CPA。原始结论为REVISE，8项意见原样保存在independent-review.json。没有修改原意见以显示PASS；以下为作者修复和测试处置，不冒充第二轮独立通过。

| 意见 | 处置 | 证据边界 |
|---|---|---|
| 1 组织器截断事项但不报告遗漏 | 增加同一次组织返回中的coverage_disposition，逐个绑定未分配原文、独立/共同前置/未知作用域；不足预算不许悄悄扩大 | 代码能校验引用和完整字段，不能证明模型发现了所有遗漏；既有Jev coverage继续参与 |
| 2 总覆盖遗漏可能包含共同前置 | 有来源的shared_gate/unclear仅阻止影响项；声明共同义务且总覆盖未决时保守保留；其余独立缺口不撤销已就绪工作 | 原COVERAGE.global的语义是遗漏独立请求，不是批准权限；无法由一项布尔结果证明没有隐藏共同义务，不新建全局总开关 |
| 3 有限出口可能忽略其他未决理由/强制读取 | 限定精确method-only理由，任意mandatory_reads、共同义务、依赖、伴随方法或多候选未决均不走此出口 | 该修复有意窄，不宣称全部多方法未决已解决 |
| 4 空performed_methods不证明文字不冒领执行 | 执行边界进入S1目标、具名纠偏与最终接收，最终宿主必须看实际最终文字而非只信空列表 | 不添加关键词拦截或伪造语义认证；程序回执仍不证明句句正确，另行评阅方法执行主张 |
| 5 新轮次只绑定完成回复，没有绑定最终接受 | 同时要求实际执行和最终acceptance记录、上下文、原始来源、文本/hash一致；被替换/未接受答案不可作为下一轮 | 本地记录是可核验来源，不是不可伪造身份认证；测试明确是夹具，不能冒充真实轨迹 |
| 6 评阅资料只自洽而非真实读取 | 从产生该答案的request/intent/outcome核对材料；传入的全部方法内容必须与该请求实际材料相同 | 无法还原的纠偏上下文不得静默填完整资料，须报告缺失/补齐真实记录 |
| 7 只凭missing=[]声称可重现原失败 | 所有普通prefix默认original_failure_reproduction_eligible=false；源窗口完整与完整历史复现分别标识 | E可新做两轮轨迹；F原图尚未找到，原始首轮不可假装重现 |
| 8 复查发现新方法却无法读取 | 剩余预算内允许复核返回read_methods；后续材料读取/交付计入原执行额度，原候选保持同一版本 | 一次复核、至多两批总读取和最终接收预留不变，不自动增加额度 |

全仓首次回归还发现共同候选诊断没有per_issue、routing_complete新字段访问该键报错；已修为诊断不能声明路由完成，保留原共同候选测试。

已经做出的修复先通过反例回归。独立模型审查仍为原始REVISE＋作者处置状态，后续不因已有测试绿而宣称模型效果通过。
