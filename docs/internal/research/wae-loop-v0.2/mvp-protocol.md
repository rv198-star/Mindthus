# WAE Loop v0.2 最小实验协议

日期：2026-09-07；#207。状态：**PROTOCOL CANDIDATE / NO MODEL TRIALS**。
上位设计：[design.md](design.md)。本次三场角色审查是设计工作，不计模型试验样本；该协议不自动授权外部模型调用或生产部署。

## 1. 要区分的假设

H1：在用途已满足时，候选能及时交接，不靠更多字段制造进度。
H2：在真实交接障碍存在时，候选只针对必要部分深化，提高首次接手的结果。
H3：显式多次循环相比相同判据的一次充分处理，有足以覆盖额外成本的增量。
H4：未知、缺权限、引用不可用和预算耗尽时，候选既不伪造完成，也不靠全部拒绝取得表面安全。

设计一致性、设施测试、模型行为、端到端价值分别报告。现有模型标签、九种角色意见或一段清晰原理不证明任何 H 成立。

## 2. A/B/C 条件保持

A：已发布 WAE 的一次充分工作，允许内部自主深入和设计，不强迫浅交接。
B：v0.2 判据，一次充分工作；与 C 使用相同候选指导、来源、权限和总 Owner 预算上限。
C：同一判据，以当前版本产物和有界检查反馈进行显式交接/深入判断；最多三个 Owner 请求，再一个 fresh 接收者请求。

三组共享按当前任务复用的启动约定、等价的来源可见性、工具条件和输出载体。协议只固定实验边界，不给 A 偷加候选语义判断，也不给 C 独占标准答案。

相同预算上限不等于相同实际计算：C 会重新读取上下文，推理与缓存计量也可能不同。报告可观察的 input/output/reasoning/cache 字段和未知项、实际请求数与时长，不用相同 cap 宣称严格计算匹配。B−A 是指导差异，C−B 是显式循环及其实际成本差异，不能自动外推为普遍方法优势。

第一波固定证据，各角色不隐含调用内部 Agent 工具循环。公开示例/语法检查由驱动器运行，可提供已冻结的反馈；隐藏验收只在最终交接后执行，不反馈 Owner 继续刷答案。模型若输出 refine，驱动器保存实际产物及观测再决定是否还有下一次预算；最后请求仍为 refine 而未完成交接则记未收敛，不强改 handoff。

不要求每次改稿都另加 Reviewer。Owner 的交接判断必须对最新材料成立；无实际证据的检查只能标明自检，不能生成假的独立验证收据。

## 3. 三个主家族及可行性检查

### F：一个完整的 P2→P3 小型审核交互切片

P1 明确批准绑定内容版本、编辑产生未批准修订、批准记录保留。P2 不改变政策。P3 读取允许来源和交接包，负责实现。

关键设计对象是显示内容与批准关系及任务已激活的跨视图一致性，不是某套字段/组件。参考解至少有两种不同合法表达。原来只因 P2 没复制 P1 段落就判失败的夹具无效；完整可达引用与合法推导应允许充分。

缺口变体必须证明实际矛盾、不可用引用或仍有本层保留的结果性决定，不能只是假设 P3 不会读。最终检查操作后状态和权限、必要状态能否辨识、实际实现是否偷偷改变上游含义。

### K：固定证据下的行为知识包

Owner 读取同一有界源码/文档集合，含相关失败路径和有限干扰。任务家族公开为定位能力与解释一次具体故障窗口/相邻改动影响，不是任意未来问题。

接收者首轮只读取知识包及用途问题，不能用源仓库掩盖摘要遗漏。相关代码行为、证据定位与条件性答案先形成可审查验收。外部幂等未知时，“本地可能再次调用”与“实际一定重复副作用”分开。

至少两个可用摘要/表示通过；准确引用却夸大保证、删去关键条件、只给“见源码”的坏例失败。若任务只需导航，允许较浅结果。固定证据阶段不评价全仓探索节省。

### S：策划到少量可检查页面

虚构完整来源和受众/行动目标提前冻结；来源允许多种准确叙事、版式和图示。Owner 处理必要论证与口径；接收者在权限内制作。

事实核对与算术检验检测硬错；多解范围审阅检查必要论证、限定和行动请求在正常阅读中可理解。若完成可渲染小页面，则记录实际渲染环境及页面结果；若只做页面表示，结论止于表示，不声称验证视觉质量或真实受众反应。

字数、图表类别、像素 hash 或单一模型美学总分不是通过标准。更换合法视觉方式但不改变含义应允许；重要限定仅存在于不可读脚注的对照应暴露风险。生成图像/视觉模型的额外调用须预先计入同一预算。

## 4. 最小先决条件：先验证实验自己

用例、公开要求、允许的答案范围、可运行参考解/可用知识表示、对照坏例、角色可见性、组别提示和评价方式在模型运行前冻结。出现多个合理解释且影响通过标准时，先修用例或保留多解，而不是等待结果后选有利解释。

独立指评价材料与受试角色的可见性隔离；同模型新上下文并非异模型独立。若作者在当前会话看过参考解，本会话后续角色模拟不作为未见输入实测。不得把同一模型扮演读者的自评当真实受众证据。

零模型调用设施自测至少覆盖：正常 handoff、refine 后版本绑定、need_input/stop 不调接收者、预算耗尽、重复请求不漏计、来源与评测隔离、过期产物不沿用检查、错误结构不自动修成有效动作、拒绝修改后原证据仍可读。它只证明驱动器可用，不证明模型能判断业务。

输入与参考解可公开开发；未见同义/授权/事实变体作为后续小样保留，不将整个题库放入作者提示中。

## 5. 预算与执行安排

第一波：F/K/S × A/B/C × 各一次，九个端到端 trial。
最大请求：3 × (A 的2 + B 的2 + C 的4) = 24。另预选三个单次边界判断，整波硬上限27次真实模型请求。

三个边界判断优先覆盖：完整引用已有充分性；同一事实的用途/结论强度变化；外部保留权限/必要数据缺失。具体版本在启动前登记，不运行后挑好例子。

探活、失败、超时、结构无效、重试和额外 LLM grader 都计入27上限。失败可使原槽位未完成，不自动补齐；预算耗尽记录 stopped-before-slot 或未收敛。手工评审也有成本，另记录，不宣称免费。

provider/model 实际返回身份、推理档位、工具权限、单请求/累计 token 与时长硬上限尚待运行前确定。网关没有底层模型证明时如实标识；不拿显示名称作证明。请求限额是实验约束，不是 WAE 语义深度上限或耗时承诺。

各 trial 清洁隔离；预先固定轮转/随机顺序，减少某一组总在环境最差时运行。保存所有失败和成本，不用各次最佳结果代表该组。

第一波不实施接收者向 Owner 的补救回流、不做途中并行部分交接。任何后续补查/修订独立记录诊断，不能回写为首次交接成功。

## 6. 如何评价与归因

逐 trial 至少记录：

- 原用途是否完成，是否正确 need_input/stop；
- 本层是否遗漏必要决定/事实/论证，是否越权；
- 已知正确约束与重要条件是否保留；
- 下层首次产物是否可用，是否被迫补上层决定；
- 是否过度深化、包办全部工作、重问既有边界或转移理解成本；
- 实际请求、耗时、可得 token/字节和能力/环境限制。

“接收者猜对了未授权政策”仍是委派失败，即使最终功能测试碰巧通过。充分交接后接收者违反明确合同仍记端到端失败，但因果标为接收者执行问题，不能全归 Loop。作者理解正确而最终压缩丢条件归交接产物损失；基础设施/评测错误另列。

主观用途评价隐藏组别与作者身份，样张顺序可反转，并允许无法判定；不把多数偏好投票当客观事实。评价者不能在看到 C 后临时新增让 A/B 失败的条件。若使用 LLM 评价，需记录其相关偏差与同模型依赖风险，成本纳入约束。

证据链最短应能回答：哪个公开义务、在何种输入下、哪份产物如何满足或违反。无需记录私有推理链。

## 7. 稳定性及极端变化

首波只观察机制错误和收益信号；一例成功不能证明稳定，一例失败也不是普遍不可行证明。

后续在同协议下有限追加重复，并用预先冻结的成对变体检查：同义改写/顺序变化维持关键结果；关键证据删除/授权变化引起必要敏感性；来源等价重构保持行为结论；真实行为变化更新结论；唯一阻塞补齐后不重复深入；正常自主选择不触发权责重谈。

允许不同合法深度。可靠性观察的是重要条件与结果的持续成立，不是词句或步骤相同。三次全成功仅为小样迹象，不报告无依据的高可靠百分比。

## 8. 继续、修订或停止研究的规则

出现越权、伪造事实、目标缩水、预算绕过或评测泄漏，停止该候选的推广，保留失败并定位；不为取得 PASS 现场改评测。

若 C 有可解释的交接改善且没有简单场景退化，才投入下一小批重复。若 B 已经提供同等观察结果且更省，没有必要先推广 C；这表示尚未取得 Loop 增量证据，而非小样已经证明统计等效。

如果 C 主要靠多读材料获益，先归因获取策略。若收益只来自一次更好提示，则优先指导改进。品质/成本冲突按已确定用户目标和风险边界解释，不在事后选择新的加权总分来选赢家。

K 的自主读取作为后续单独实验：共同只读接口、来源与累计读取预算；B 也有正常检索能力。全部内部模型请求计数。第一波的27上限不自动扩大为动态工具批次的授权。

## 9. 当前可交付与证明上限

本轮只有方案、对抗反例、裁定和本协议。夹具、独立 oracle、驱动器、模型试验和实际价值尚未实现/获得。

下一步是把三个小场景做成公平可行的试题与验收，完成设施自测，再决定启动有限试验。没有理由先接入 WFF、EKRI、Slidethus 生产链，也不做通用 WAE runtime 发布。
