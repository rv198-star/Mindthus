# 第三场评审：Slidethus——事实没错，不代表策划已经足够交接

日期：2026-09-07。关联：#207 / Draft PR #208。
评审输入为固定提交 `59d8cbfc81531978a59fc0d63638d593b6499dba` 的 WAE Loop v0.1。
方式：本会话 ChatGPT 的策划、信息设计、受众与证据三立场对抗审查；不是真人发言纪要、不称上下文隔离。下列提案数据全部为合成示例；未制作幻灯片或进行模型/受众实验。

## 1. 三种立场的首轮冲突

**策划/叙事责任方**：受众、核心主张、证据和行动请求已经写清，就应该让视觉专家设计，不应把策划扩成逐像素施工图。

**信息设计承接方**：图形、顺序、标题和版式会改变读者理解，不可能把视觉完全视为中性的机械呈现；有些表达选择我必须有权决定。

**受众与证据反方**：两边都可能只证明“材料完整”。一个事实全对但让听众不知道要批准什么的演示，仍没有达到用途；反过来，一张极具说服力但隐去样本限制的图，也不是成功。

初判：原方案保护创意自由正确，但需要把“事实保真”与“用途可用”同时纳入交接充分性，并阻止视觉选择改写论证强度。

## 2. 争议 S-01：完整的事实列表是不是合格策划

定位：v0.1 §4、§9、§10 的 WAE/TVG 边界。

最小反例：策划稿准确列出方案、数据、风险、预算，却只有“背景—结果—结论”标题。受众需要决定是否批准一个有上限的试点，但稿件没有建立证据为何支持该行动、哪些条件限制承诺。制作方只能自己重建论证。

错误出口：事实没有错，剩下是让它更漂亮或更动人，归下层/TVG，立即 handoff。

质询：受众理解和行动请求本来就在启动目的中，不能因它们难测量而降成装饰；但不能要求策划为每页填写同一套模板。

裁定 R7：必要论证关系属于用途要求时，必须明确到制作方不必重做核心策划。可以是一段因果/非因果说明、一张粗略逻辑图或少量页面关系，而不是固定每页字段。若单纯表达优化已在承接者合法范围内且有能力完成，则允许放手。TVG 是可选工作方法，不是把未尽责任转出的名称。

## 3. 争议 S-02：视觉自由什么时候会改变事实含义

合成来源：前一期间完成40项/100个机会，后一期间完成60项/200个机会；样本不支持因果归因。

成立的表达：完成数量增加50%；完成率从40%降至30%，减少10个百分点。后者并非由前者自动覆盖。
不成立的表达：“转化率提升50%”“方案证明带来50%效率提升”。

策划立场可以选择强调数量增长；受众反方要求把对决策重要的分母、样本限制和适用窗口一起保留；信息设计立场反对用一个固定图表样式作为唯一答案。

裁定 R5/R7：策划确定主张、比较口径及结论强度；制作可选柱状图、对照卡或表格，但必要条件应在正常阅读中可理解。所有原始数字和一句极小脚注都存在，不等于误导已经消失。禁止的是错误推断，不是某个图表类型或所有非零起点。

反向控制：任务只要求客观列出数量与比例，不要求作因果判断；制作选择另一种准确图示不应被判未遵守策划。

## 4. 争议 S-03：要不要在交接前先渲染完整稿

反例一：核心图形的效果依赖一个不能可靠表达双尺度的工具。仅凭文字签收，容易误导。反例二：普通三页演示却被要求完成全套模板、十轮渲染和美学审查才能放手。

裁定 R2/R8：只有影响必要含义或已知能力风险的部分需要低成本表达探针，例如一页草图/一个可渲染的核心图。探针不是完整交付，也不自动改变阶段所有权；工具调用和失败均计入原预算。已清楚且无相关风险的普通页不强制渲染。

能力不足时，上层可在授权范围内补一个参考表达、改用同样满足目的的可实现设计，或请求合适承接者。不能因为当前工具限制就擅自删除受众需要的重要对照，也不要求上层包办所有页面。

MVP 限定：可以使用固定的最小页面表示和渲染环境，不接完整 Slidethus。如果只验收文本/页面描述，则结论只到语义交接，不能声称视觉成品或真实说服效果已验证。真实页面只要在任务要求的表达边界内，多种合法方案都可通过。

## 5. 争议 S-04：美学目标是不是只能交给下层，永远不影响 Loop

最小反例：用户明确要求“给经营负责人在短时间内理解保守试点决策，克制、可信、对照清楚”。材料事实齐全，但策划提供的叙事顺序先展示未经验证的收益承诺，重要限定最后才出现。

裁定：风格和受众是有效约束，但其实现通常归下层；当策划自身的结构使这些约束无法实现时，策划应修订。不能把主观“还可更高级”变成无限下钻，也不能把用户明确的审美/表达目标排除出结果。

验收分开硬错误、用途可用性和偏好差异。硬错误如数字口径与承诺越界；用途可用性如能否准确指出要批准的行动及依据；偏好差异如两种都易懂的视觉风格。第三类不得因偏离参考样张而自动失败。

## 6. 争议 S-05：没数据时继续深化能否产生价值

来源只有有限的观察性样本，任务是请求一个有边界的试点。承认限制、提出有限验证行动可以是充分策划，不必为了证明规模化收益继续编故事。

若任务明确要求证明已实现某项收益，现有数据不能支持，则应请求数据或说明无法完成该结论。不能临时把任务改成“介绍一个可能性”取得通过。

裁定沿用 R4：所需结论强度由启动用途决定。制作时省略 caveat、改强标题等实质变化需要回到该责任边界；不重新确认整份品牌与角色约定。

## 7. 评价机制本身受到的质询

同一模型写策划、扮演受众、给美学总分，可能让偏好的表达形式自我通过。评审角色数量不构成统计独立性。

MVP 应先用来源核对与算术检查抓硬错误，再做隐藏组别、允许多解的用途审阅；可以更换样张顺序并允许“无法判定”。同一会话扮演受众只能提供设计线索，不作为真实读者理解证据。

外部评价依据限于方法论：LLM-as-judge 的位置、篇幅与自偏好风险已被相关研究讨论，但不据旧模型实验推断本候选的误差率。[Judging LLM-as-a-Judge, 2023](https://arxiv.org/abs/2306.05685)。

## 8. 本场接受与拒绝

接受：R7 用途可用性与核心论证不能由“事实齐全”替代；R5 重要限定在交接压缩和视觉表达中保持；R8 风险相关的最小表达探针与分层验收。

拒绝：逐页固定所有字段和像素；无限美学审稿；事实准确即自动可用；制作方可以更改主张以适应图表；同一模型的角色数量代表独立验证；将计划稿测试写成真实 PPT/受众效果证明。

修订后纸面回查：有数字无论证关系→必要策划补足；合法多图形→允许委派；数量/比例混淆→修订；有限试点目的且限制清楚→允许带条件交接；要求无证据收益保证→need_input；工具只能误导性表达→改可行表达或寻求能力支援。

本场结论：**修正后可以进入小型策划—制作交接实验；表达效果和泛化仍待真实结果。**
