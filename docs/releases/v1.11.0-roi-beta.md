# Mindthus v1.11.0 ROI Beta

发布日期：2026-10-03。作为 `v1.11.0` GitHub Release 的 supplemental experimental asset 同步提供。

`mindthus-beta-1.11.0-roi-beta.tar.gz` 通过确定性组装绑定精确 `v1.11.0` Stable shared core。共享方法继承本版减负；独立入口继续使用原SRA-compatible ROI Thin Core，没有复制一套方法实现。

本版不增加Beta运行时能力：保留原Thin Core、历史ROI.2 3L5S Anti-Spiral纠偏正文、Beta identity/namespace及诊断坐标。共享3L5S已精简，打包器只为其现有段落调整替换锚点，继续要求精确一次匹配；旧资格记录与旧profile不改写。

Beta-specific自然唤起、相对质量、跨模型一致性与Token ROI未新增测量；Stable的40条回归不能冒充Beta专项收益证明。主力使用Sol 6.1以下版本的用户，不建议仅为本版优化升级；Beta仍是可选实验包，不替代Stable、不自动迁移。

源tag：`v1.11.0-roi-beta`。包内 `beta-profile.json` 记录Stable ref/tree及Beta assembly source。Stable/Beta可独立安装或移除，回退使用保留的v1.10.1资产。详细变化见[v1.11.0说明](v1.11.0.md)。
