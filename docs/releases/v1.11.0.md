# Mindthus v1.11.0 — Sol 6.1 减负优化

发布日期：2026-10-03。

本版主要针对 **Sol 6.1 降低不必要的 token 消耗**。模型已有足够判断和执行能力时，减少重复提示、资料读取往返与无必要的流程展开；重要判断、证据和权限边界继续保留。

**升级建议：主力使用 Sol 6.1 的用户可升级；主力仍使用 Sol 6.1 以下版本的用户，不建议仅为本次优化升级，可继续使用 v1.10.1。** 这是收益证据的范围，不是旧模型不兼容声明。只维护一份共享方法核心，不按模型拆分发行版本。

## 本版变化

- 入口按剩余判断缺口选择方法，已有依据充分就结束选路；不按话题词机械调用，用户显式指定方法仍执行。
- 精简重复的认知要求和伴随镜头。SELA/MPG按缺口补位，EDSP无需先绕经3L5S；明确小任务直接执行，复杂任务再展开。
- WAE合并重复的适用范围介绍，保留控制权、语义所有权、必要证据和升级规则；TVG已有充分改善可以退出，固定句序不充当语义判断。
- TPlan复用轻量checkpoint，必要时展开状态与决策；脚本权限、证据引用、unknown与完成约束保持。发布前补回现有决策脚本路径并压缩重复说明，满足原入口体积上限。
- 一个共享核心，继续提供现有插件和Skills布局。TPlan runtime generation仍为 `1.5.4`。

## 实测支持什么

最新比较是 **RC01 → 后续候选**，不是 v1.10.1 → v1.11.0 的直接统计。16个公开开发例在Sol 6.1两臂运行32条，Astra抽检8条，共40条真实交付。模型配置均为medium。

|本轮配对|宿主调用|输入token|宿主会话秒|
|---|---:|---:|---:|
|Sol 6.1，16组|25→21|470,840→391,124（少16.9%）|574.254→523.121（少8.9%）|
|Astra，4组|7→6|132,235→112,568（少14.9%）|145.244→146.255（基本持平）|

主要节省来自减少不必要的方法读取，而非只缩短文字。输入token包含公共宿主上下文，缓存影响实际费用；不能把节省比例直接当作账单降幅，也不承诺每个任务提速。

执行端按事前判据知晓分组核对：38份可用，CSV题两臂均部分可用——主要修复正确，但都遗漏显式含引号/逗号字段的验证样例。未观察到候选新增关键质量回归。这不是独立盲测、未见样本认证或普遍质量优势证明。

最新批次使用59/120次调用，无新增未知或自动重试；余量不继续消耗。前一44条实验及98次历史成本另行保留，包括已接受风险但远端仍未知的旧请求，不能把整个研究称为无故障首发。真实金额与底层HTTP精确次数保持unknown。

被测候选：`131ab6e4d7b04e3964193dc95c869f6eaad16730`；[固定证据与40份原文](https://github.com/rv198-star/Mindthus/blob/b8a40506d4aa012d9c256990ad07328b9afcb5bd/docs/internal/optimization/sol61-slim-v0/post-rc01-regression/REPORT.md)。发行版本另含版本/打包接线及上述TPlan文字整理，未冒称这些发布改动已运行新的模型批次。
