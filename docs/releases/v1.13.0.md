# Mindthus v1.13.0 — Explain HTML V2、Visualizations 与自适应主题

发布日期：2026-10-08。发行性质：**Stable / v1.13.0**。此前源码预发布候选为 [v1.13.0-rc.1](https://github.com/rv198-star/Mindthus/tree/v1.13.0-rc.1)；本版在已验收功能基础上整理发行信息，没有重做历史模型生成。

## 核心变化

### Explain HTML V2

- 新增短稿到确定性 HTML 的共享编译器，Node >=20 能运行时优先布局，缺失或不可用时退回 Python。Node/Python 改变布局实现，不改变源稿事实、判断边界和交付权限；无运行时安装动作。
- 支持紧凑的 callout、table、flow、sequence 与 progress/range，保留未估计、区间与不同单位原义，不以工作块数量虚构整体完成百分比。
- 图解默认适配阅读宽度，保留原始大小与文字关系说明；压缩页头、边距与面板装饰，增强组合图块和明细呈现。
- Explain Skill 版本升级为 `1.1.0`、HTML V2 编译器正式版本 `2.0.0`；旧开发期 `-dev` 版与本次 Stable 清晰区分。
- 支持源稿恢复、按块更新及源码摘要校验。TPlan 拥有自己的状态与验收逻辑；Explain 仍只负责展示，不接管 Mission 决策或权限。

### ChatGPT 内嵌交付与系统明暗主题

- ChatGPT 当前对话存在 Visualizations / AppBlock 时，交互 HTML 以原生对话组件作为主要交付；Codex 按当前宿主真实交互能力执行，其他宿主保真降级，不把 HTML 下载或截图冒充内嵌成功。
- 默认跟随宿主可用的明暗主题，缺少宿主绑定时使用系统 `prefers-color-scheme`；显式用户覆盖优先。亮/暗两套配色覆盖正文、表格、状态标签、SVG 图中文字和控件。
- 依据真实 ChatGPT 对话截图与用户反馈改进深色模式的对比度。展示样例使用编译器支持的结构与主题规则，但做过少量手工精简和主题绑定；**编译器逐字 HTML 原样提交至宿主并完整操作的独立回执尚未取得**，仍在 [#228](https://github.com/rv198-star/Mindthus/issues/228) 跟进。

## 验证边界

- #228 固定 18 次真实生成与独立评审沿用原封存结果，不重复调用模型；先前宽流程图显示问题已专项修正。
- Explain 编译器、源稿恢复、Node/Python 回退、真实浏览器缩放与主题切换、宿主主题反向覆盖、无 JS 可读路径与打包结构都已覆盖相应工程测试。
- 用户已确认 ChatGPT 对话内演示及跟随系统主题的实际视觉效果；这仅支持已展示视图的体验验收，不自动证明全部编译产物在各宿主原样交付。
- 本版不承诺固定的模型质量、token/延迟节省或普遍性收益。#229 的 tree/timeline 与 V2.1/V3 不属于此次正式发行。

## 兼容与发行约束

- 这是 v1.12.0 之后的功能 minor release；既有 `/mindthus:explain` 模式及默认 clarity 入口继续有效。
- TPlan runtime generation 保持 `1.5.4`，不触碰已存在的 Mission 数据、状态或验收结论。
- 按 [Stable 发行规则](../internal/release-defaults.md)，**v1.13.0 不发布 ROI Beta**。既有 Beta 标签/资产保留，后续需单独授权。
