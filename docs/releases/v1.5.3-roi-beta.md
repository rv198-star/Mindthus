# Mindthus v1.5.3 ROI Beta 发布说明

发布日期：2026-07-25

`v1.5.3-roi-beta` 是作为 `v1.5.3` GitHub Release 的 supplemental experimental asset
发布的可复现源码 tag，不是独立的 Stable release，也不取代 `v1.5.3 Stable`。

## 组成与边界

- Shared Product Core 固定为 `v1.5.3` / `57319d8da57c367eed42e386b4bfafb477e91bea`；因此
  #141、#142、#143 的 TPlan 修复与 Stable 字节一致。
- ROI.2 的 `using-mindthus` 薄入口覆盖层固定为其已资格验证的 commit，另有一条固定的
  3L5S Anti-Spiral 句子替换。除 namespace 与运行时诊断坐标外，其他产品能力均来自上述
  Stable core。
- 包的身份是 `mindthus-beta`，包括 package、marketplace、cache 与 skill namespace，
  可以与 Stable 独立安装、验证、移除。

## 可验证发布物

GitHub Release 资产为 `mindthus-beta-1.5.3-roi-beta.tar.gz`。它由
`beta/2.0-beta/build-internal-beta.py` 从干净 checkout 组装，并由 Release 的
`SHA256SUMS` 同时覆盖 Stable plugins、Stable skills 与此 Beta 压缩包。

该包仅面向高能力 Codex / GPT-Sol 的受限实验。它不自动迁移用户配置或工作流；需要完整
被动唤起、跨模型一致性或保守默认行为时，应安装 Stable。
