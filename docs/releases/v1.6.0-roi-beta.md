# Mindthus v1.6.0 ROI Beta 发布说明

发布日期：2026-08-06

`v1.6.0-roi-beta` 是作为 `v1.6.0` GitHub Release 的 supplemental experimental asset
发布的可复现源码 tag，不是独立的 Stable release，也不取代 `v1.6.0 Stable`。

## 组成与边界

- Shared Product Core 固定为 `v1.6.0` / `cb7057957660f042aff09a180cf0a9633e65088f`。
- ROI.2 的 `using-mindthus` 薄入口覆盖层固定为已资格验证的历史 commit；另有一条固定的
  3L5S Anti-Spiral 句子替换。
- 除上述两处运行时合同、Beta identity、namespace 与 runtime diagnostic 坐标外，其他
  产品文件均从 v1.6.0 Stable core 构建并保持可归一化比较。
- 因此该包继承 Judgment Trace v1.1、Case Export v1、`case-prep`、case collection、
  Test Lifecycle 与 v1.6.0 Stable 中的现有 TPlan 能力。
- TPlan runtime generation 继续保持 `1.5.4` / `mindthus-v1.5.4`，与配对 Stable 一致。

## 独立身份

包的身份是 `mindthus-beta`：

- package：`mindthus-beta`
- marketplace：`mindthus-beta`
- cache：`mindthus-beta/mindthus-beta/1.6.0-roi-beta`
- skill namespace：`mindthus-beta:*`

它可以与 Stable 独立安装、验证和移除，不触发用户配置、安装或工作流的自动迁移。

## 可验证发布物

GitHub Release 资产：

- `mindthus-beta-1.6.0-roi-beta.tar.gz`

源码 tag：

- `v1.6.0-roi-beta`

构建命令：

```bash
python3 beta/2.0-beta/build-internal-beta.py \
  --out /tmp/mindthus-1.6.0-roi-beta-marketplace \
  --archive /tmp/mindthus-beta-1.6.0-roi-beta.tar.gz
```

构建器要求干净 checkout，固定 Shared Product Core、历史 ROI overlay 与资格 profile，
并生成 byte-reproducible archive。v1.6.0 Release 的 `SHA256SUMS` 同时覆盖 Stable
plugins、Stable skills 与该 Beta 压缩包。

## 使用边界

该包只面向高能力 Codex / GPT-Sol 的受限 ROI 实验。需要完整被动唤起、跨模型一致性、
保守默认行为或一般生产使用时，应安装 Stable。

本发布不声称：

- ROI.2 已在所有模型和 host 上重新资格验证；
- 薄入口在所有任务上优于 Stable；
- 新增 v1.6.0 案例能力改变了历史 ROI.2 的因果证据；
- Beta 可以代替 Stable。
