# Mindthus v1.6.0 Release Candidate 说明

目标发布日期：2026-08-06

状态：Release candidate；`v1.6.0` tag 与公开 assets 尚未发布。

## 版本定位

`v1.6.0` 是 1.x Stable 线的判断可观测性、案例准备和测试治理 minor release。

本版不新增判断方法。它把已经存在的判断、benchmark 和 TPlan 运行事件整理成可验证、
可复核、用户控制的案例材料，并建立测试生命周期治理基础。

## Judgment Trace v1.1

- 新增 `mindthus.judgment-trace.v1.1`。
- decision delta 使用 `true / false / unknown`，避免把“未评估”错误记录为“未变化”。
- 新增 comparison basis、comparison reference 和关键字段来源标签。
- benchmark runner 输出每案 Judgment Trace 和 JSONL 索引。
- validator 与 Case Export 继续读取 legacy `mindthus.judgment-trace.v1`。
- Trace 只记录可观察事实、有限 evaluator label 和注释，不记录 private chain of thought。

## Case Export v1

- 新增本地、用户主动触发的 `mindthus.case-export.v1` 包。
- 默认不包含完整 prompt、完整 answer、附件、任务日志、环境变量或凭据。
- 显式文本摘录需要用户确认已经人工检查和脱敏。
- 隐私扫描阻断常见 private key、token 和密码形态，并提示可能的身份信息。
- 导出与分享是两个独立动作；没有上传端点或后台遥测。

## case-prep

新增显式工具 skill `case-prep`，不进入 `using-mindthus` 的被动判断路由。

支持：

- 当前判断案例；
- 归档 benchmark case；
- bounded TPlan case packet；
- `/mindthus:case-prep 导出当前所有mindthus相关案例` 批量集合。

批量集合保持每个 Judgment / TPlan 案例的独立合同，不生成 mega-trace。集合和所有嵌套案例
都会在打包前重新验证。

TPlan 案例使用一次原子只读 snapshot，并从同一 snapshot 派生 Pulse-compatible view。
存在 pending Mission transaction 时 fail-closed，不恢复、不修改 Mission。案例包不复制完整
Mission、任务树、evidence stream、step logs、execution trace 或 telemetry payload。

## Test Lifecycle

- 新增 `tests/test-lifecycle-registry.json` 和校验脚本。
- 每个可执行测试文件必须恰好归属一个 lifecycle group。
- 区分 active gate、active regression、historical guard 和未来清理候选。
- 第一波清理移除了重复或错位的历史 release wording assertions，但保留唯一历史合同证据。

## 兼容性

- Judgment Trace v1 继续可读。
- Case Export v1 可包含 v1.1 或 legacy v1 Trace。
- Python 3.10 的 runtime config 读取提供受限 fallback；CI 继续使用 Python 3.11。
- **TPlan runtime generation 保持 `1.5.4` / `mindthus-v1.5.4`。** 本版没有修改 TPlan
  runtime fingerprint files；不应仅因为发行版号升为 1.6.0 就让既有 Mission 失配。
- 插件和发行包 manifest 使用 `1.6.0`。

## 验证

Release candidate 在仓库根目录运行：

```bash
python3 -m compileall -q scripts skills tests
python3 scripts/check-test-lifecycle.py
python3 -m unittest discover -s tests -q
python3 scripts/build-release-pack.py --package plugins --out /tmp/mindthus-plugins
python3 scripts/build-release-pack.py --package skills --out /tmp/mindthus-skills
```

验证范围包括：

- Judgment Trace v1/v1.1 与 Case Export；
- case-prep 的 judgment、benchmark、TPlan 和 collection 模式；
- Codex plugin、Claude Code plugin、Claude portable、Codex portable 和 OpenCode portable；
- strict runtime fingerprint；
- TPlan 案例只读、pending transaction fail-closed 和嵌套集合重验证；
- 完整 unittest suite 与 Test Lifecycle registry。

## 发布边界

计划发布：

- `mindthus-plugins-1.6.0.tar.gz`
- `mindthus-skills-1.6.0.tar.gz`
- `SHA256SUMS`

本版不计划发布新的 ROI Beta。`v1.5.4-roi-beta` 仍是 `v1.5.4` Release 的历史
experimental asset，不自动升级为 1.6.0。

Release candidate 不声称：

- Judgment Trace 能证明判断正确或因果价值；
- 隐私扫描能证明匿名；
- case collection 中所有候选都彼此独立或值得进入 benchmark；
- Test Lifecycle 已完成大规模测试删除；
- TPlan runtime 已升级到新的 generation。

实际发布前仍需创建 tag、构建最终压缩包、生成 SHA256SUMS、上传 assets，并将 README 的
公开下载从 v1.5.4 Stable 切换到 v1.6.0。
