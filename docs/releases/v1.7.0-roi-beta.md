# Mindthus v1.7.0 ROI Beta 发布说明

发布日期：2026-08-09

`v1.7.0-roi-beta` 是作为 `v1.7.0` GitHub Release 的 supplemental experimental asset 发布的
可复现源码 tag，不是独立 Stable release，也不取代 `v1.7.0 Stable`。

## 组成与边界

- Shared Product Core 固定为 `v1.7.0` 发布 commit；Beta profile 记录精确 commit 与 tree oid。
- ROI.2 的 `using-mindthus` 薄入口继续固定到已资格验证的历史 implementation / qualification
  refs；另保留一条固定 3L5S Anti-Spiral contract correction。
- 除上述两处 runtime contract、Beta identity、namespace 与 runtime diagnostic 坐标外，
  其他产品文件均从 `v1.7.0` Stable core 构建。

因此 Beta 会继承 `v1.7.0` 的 WAE Ownership Closure、Judgment Trace、Case Export、case-prep、
Test Lifecycle 与现有 TPlan 能力，而不会复制一套独立产品核心。

## WAE Ownership Closure 继承

Beta 中 WAE 与 Stable 保持同源：`Ownership Closure` 仍是条件模式；`Semantic Ownership
Leakage`、`Mechanical Boundary` 与 Evidence reopening 规则一致；execution repair 不会被
改写成 generic ownership loop；TPlan runtime ownership 不发生变化。ROI overlay 不拥有或
改写 WAE 方法语义。

## Runtime delta

允许的 runtime delta 仅包括：

1. `skills/using-mindthus/SKILL.md` 使用历史 ROI.2 thin-core overlay；
2. `skills/3l5s/SKILL.md` 应用资格验证过的单句 Anti-Spiral correction；
3. `.codex-plugin/plugin.json` 改为 `mindthus-beta` identity / `1.7.0-roi-beta` version；
4. `scripts/log-mindthus-runtime.py` 改到 Beta version / marketplace / cache 坐标；
5. plugin 内 textual `mindthus:` skill references 重写为 `mindthus-beta:`。

其他 shared owner tree 必须与 Stable 一致（namespace rewrite 归一化后逐字节一致）。

## 发布形态

- 源码 tag：`v1.7.0-roi-beta`；
- GitHub Release：与 Stable 共用 `v1.7.0` Release；
- asset：`mindthus-beta-1.7.0-roi-beta.tar.gz`；
- package / marketplace / cache / skill namespace：`mindthus-beta`；
- Marketplace 自动发布：否；自动迁移：否。

## 验证

Beta 构建必须证明 shared core commit/tree 精确匹配 Stable、历史 ROI.2 refs 仍有效、runtime
Delta 不超出声明范围、WAE 等非 overlay owner tree 与 Stable 一致、Beta namespace 隔离、
runtime diagnostic strict pass、archive 可重现、package profile/capability register 可审计。

这些验证证明构建组成和边界，不证明 ROI Beta 在所有模型或 host 上都优于 Stable。
