# Mindthus v1.7.0 发布说明

发布日期：2026-08-09

发布 tag：`v1.7.0`

## 版本定位

`v1.7.0` 是 1.x Stable 线的 WAE 方法能力 minor release。

本版解决的是第一层 control assignment 之后仍可能存在的缺口：名义 semantic owner 已经
分配正确，但 delegation 链中的 helper / adapter / mapper / generator 仍可能自行决定会改变
最终结果的语义。WAE 现在可以在这种信号出现时条件性进入 `Ownership Closure`，继续细化
ownership，直到最后一个非机械决策点。

## Ownership Closure

核心规则：

> Ownership follows semantic choice; Workflow follows deterministic consequence.

新增能力：

- `Ownership Closure`：条件性的 WAE 第二层，不是所有任务必跑的新 ceremony；
- `Semantic Ownership Leakage`：识别 semantic choice 通过 delegation 泄漏到 nominal helper；
- `Ownership Boundary Refinement`：只沿可能携带语义选择的 delegation boundary 收敛；
- `Mechanical Boundary`：semantic remainder 为零后停止，让确定性后果回到 Workflow；
- Evidence-driven reopening：真实 evidence 若暴露新的 semantic remainder，可以推翻此前
  closure 判断；普通 implementation defect 只是 execution repair，不会自动移动 ownership。

## Acceptance-first

#149 在实现前先冻结 OC-01～OC-08 八类验收场景，覆盖普通 WAE 不误触发、隐藏 semantic
choice、Mechanical Boundary 停止、Evidence reopen、execution retry 负例、WAE/TPlan 边界、
跨领域泛化和 unknown input fail-closed。实现后按冻结案例逐项回看，并由 WAE contract tests
保护这些边界。

## WAE / TPlan 边界

本版没有把 WAE 变成 TPlan Lite。

- WAE：谁拥有 result-changing semantic choice，这个 ownership 是否闭合；
- TPlan：Mission/task state 如何继续，负责 ordering、blocker、checkpoint、recovery、
  resumption 与 lifecycle control。

WAE 没有新增 Mission、任务树、checkpoint、persistent ledger、Schema 或新 Gate。

## v1.7.0 ROI Beta（GPT/Sol）

同一个 GitHub Release 同时提供 `mindthus-beta-1.7.0-roi-beta.tar.gz`。

ROI Beta 从冻结的 `v1.7.0` Stable core 重新组装，因此继承 WAE Ownership Closure，并继续
继承 Judgment Trace、Case Export、case-prep、Test Lifecycle 与现有 TPlan 能力。它保留
既有资格验证的 ROI.2 薄入口，只允许 `using-mindthus` ROI.2、单句 3L5S Anti-Spiral、Beta
identity/namespace 与 runtime diagnostic 坐标这些 runtime delta。

Beta 使用独立 `mindthus-beta` identity，不替代 Stable，也不自动迁移用户安装或工作流。
详细边界见 [v1.7.0 ROI Beta 发布说明](v1.7.0-roi-beta.md)。

## 兼容性与运行边界

- Stable package version：`1.7.0`。
- **TPlan runtime generation 保持 `1.5.4` / `mindthus-v1.5.4`。** 本次 WAE 方法升级没有修改
  TPlan runtime fingerprint files。
- `wae-fidelity-v0.1` 保持兼容；Ownership Closure 是条件动作，不升级为所有 WAE 输出的
  无条件 shape requirement。
