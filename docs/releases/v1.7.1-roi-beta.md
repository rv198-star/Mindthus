# Mindthus v1.7.1 ROI Beta 发布说明

发布日期：2026-08-18

`v1.7.1-roi-beta` 是作为 `v1.7.1` GitHub Release 的 supplemental experimental asset 发布的
可复现源码 tag，不是独立 Stable release，也不取代 `v1.7.1 Stable`。

## 组成与边界

- Shared Product Core 固定为 `v1.7.1` main release commit
  `dca73c1ff1710eca3d5b56216c374ce6c2240117`，Beta profile 同时记录精确 tree oid。
- ROI.2 的 `using-mindthus` 薄入口继续固定到既有 qualification / implementation refs；
  另保留已资格验证的单句 3L5S Anti-Spiral correction。
- 除上述 runtime contract、Beta identity / namespace 与 runtime diagnostic 坐标外，其他产品文件
  均从 `v1.7.1` Stable shared core 构建。

因此 Beta 自动继承本次 Stable 的 `Competitive-frame convergence / 竞争框架收敛` 与
`Visible Translation Boundary / 可见表达翻译边界`，同时继续继承 WAE Ownership Closure、
Judgment Trace、Case Export、case-prep、Test Lifecycle 和 TPlan 能力。上述 C-lite 修复属于
`shared-product-core`，ROI overlay 不拥有或改写它。

## Runtime delta

允许的 runtime delta 仍仅包括：

1. `skills/using-mindthus/SKILL.md` 使用历史 ROI.2 thin-core overlay；
2. `skills/3l5s/SKILL.md` 应用资格验证过的单句 Anti-Spiral correction；
3. `.codex-plugin/plugin.json` 改为 `mindthus-beta` identity / `1.7.1-roi-beta` version；
4. `scripts/log-mindthus-runtime.py` 改到 Beta version / marketplace / cache 坐标；
5. plugin 内 textual `mindthus:` skill references 重写为 `mindthus-beta:`。

其他 shared owner tree 必须与 Stable 一致；namespace rewrite 归一化后逐字节一致。

## 发布形态

- 源码 tag：`v1.7.1-roi-beta`；
- GitHub Release：与 Stable 共用 `v1.7.1` Release；
- asset：`mindthus-beta-1.7.1-roi-beta.tar.gz`；
- `SHA256SUMS`：覆盖 Stable plugins、Stable skills 与 ROI Beta 三份归档；
- package / marketplace / cache / skill namespace：`mindthus-beta`；
- Marketplace 自动发布：否；自动迁移：否。

## 验证

发布前必须证明：shared core commit/tree 精确匹配 v1.7.1 Stable；历史 ROI.2 refs 仍有效；
runtime delta 不超出声明范围；包括 competitive-frame convergence 在内的非 overlay shared
capabilities 与 Stable 同源；Beta namespace 隔离；runtime diagnostic strict pass；archive
两次构建字节一致；package profile / capability register 可审计；下载后的三份 release assets
通过新的 `SHA256SUMS`。

这些验证证明构建组成、隔离与可复现性，不证明 ROI Beta 在所有模型或 host 上都优于 Stable。
