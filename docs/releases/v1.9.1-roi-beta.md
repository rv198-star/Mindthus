# Mindthus v1.9.1 ROI Beta 发布说明

发布日期：2026-09-05

`v1.9.1-roi-beta` 是 `v1.9.1` GitHub Release 的 supplemental experimental asset，
与 Stable 同步发布，不是独立 Stable release，也不取代 `v1.9.1 Stable`。

## 组装边界

- Shared Product Core 固定为精确 `v1.9.1` release commit / tree，并继承本次累计 Demand、
  prepared-input anchor、篡改阻断与 Repair 边界修复。
- Runtime delta 保持既有 `SRA-compatible ROI Thin Core`、历史 ROI.2 单句 3L5S Anti-Spiral
  correction、Beta identity / namespace 与 diagnostic 坐标。
- Stable shared core 与 Beta overlay 分开验证；Beta 不复制或改写 Stable 的 SRA 判断权威。
- 本版没有新增 Beta 专属方法、route、自然唤醒承诺或自动迁移行为。

## 证据上限

Beta 资格验证只覆盖 exact shared core、包装面、namespace isolation、strict runtime
diagnostic 与可复现归档。Beta-specific 自然唤醒率、相对胜率和 Token ROI 未重新测量，
因此不作新的模型质量或商业效果声明。

## 发布形态

- source tag：`v1.9.1-roi-beta`
- GitHub Release：与 Stable 共用 `v1.9.1` Release
- asset：`mindthus-beta-1.9.1-roi-beta.tar.gz`
- checksum：收录于同一 Release 的 `SHA256SUMS`

该归档使用独立 `mindthus-beta` Codex plugin / marketplace identity。需要完整被动唤起、
跨模型一致性或保守默认行为时，应安装 Stable，而不是 ROI Beta。
