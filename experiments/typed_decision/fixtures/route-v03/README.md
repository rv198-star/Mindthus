# v0.3 合成工程夹具

全部为 `synthetic / offline_fixture`。A–F 是场景，①／②是消费方式。
八份 JSON 的 `input` 是运行材料，`answers` 是注入观察；`reviewer_only` 仅供测试断言，不能传给宿主。
它们用于发现接线、状态与恢复缺陷，不能用来证明 Jev 检测准确率或纠偏收益。

- A：简单直接任务。
- B：单方法控制职责分析。
- C：方向与承载的主辅协作。
- D：前置被接受后执行后继。
- E：两轮 Skills 范围纠正；简单解释成立的反向控制。
- F：已有 4K 的软件补救；购前显示取舍的反向控制。

E/F 多轮文本均为合成，不是补写历史缺失助手轮次；作者和来源在 conversation 中明确标注。
测试宿主文本同样为注入回执，观察值不能视为对该文本的实际模型判断。
`tests/test_route_control_v03.py` 的八夹具子用例从公共入口消费、恢复并校验最终状态。
CLI 使用固定 `answers`；若人工在该夹具里提交修订，它不会自动模拟“修订已经正确”。
