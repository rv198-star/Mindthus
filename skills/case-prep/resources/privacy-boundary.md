# Case Prep Privacy Boundary

All modes are local-only and review-required.

Defaults:

- no automatic upload;
- no raw prompt or full answer;
- no arbitrary attachments;
- no full TPlan Mission/runtime files;
- no private chain of thought;
- no silent environment or private-file capture.

Text excerpts must be explicitly selected and confirmed as redacted. The runtime blocks
several common credential patterns and warns on limited identifiers such as email
addresses and home paths. A passing scan does not prove anonymity or consent.

The user or authorized agent must read every generated file before sharing the archive.
